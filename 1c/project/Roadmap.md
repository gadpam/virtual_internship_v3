# Дорожная карта года: Виртуальная стажировка 1С

Год = 4 квартала = 53 спринта (вводный sprint_0 + 52 рабочих недели) = 313 заданий (task_0 … task_312) + 53 code review. Спринт = 1 неделя = 6 заданий (в sprint_0 задание одно — вход в проект).
В конце каждой группы спринтов — code review. В конце квартала — milestone-спринт
(демо + защита + ретро). Дальше идти нельзя, пока milestone не сдан.

## Как читать программу (сверху вниз)

1. `1c/README.md` — легенда, формат, требования, что вы получите.
2. `project/Roadmap.md` — этот файл: кварталы, месяцы, точки контроля.
3. `project/Skills_matrix.md` — требование рынка → где отрабатывается.
4. `project/Project_content_task_by_task.txt` — оглавление года: все 313 заданий.
5. `project/sprint_N/SprintOverview.txt` — цель и результаты недели.
6. `project/sprint_N/task_M/YourTask.txt` — конкретное задание и его Definition of Done.
7. `project/sprint_N/task_M_code_review/CodeReviewTask.txt` — проверка в конце недели.

Планировать год заново не нужно: он уже разложен. Ваша работа — идти по нему и
фиксировать результат в `internship/documentation/`.

## Ритм недели

- Пн–Вт: 2 задания (новое знание, чтение, разбор);
- Ср–Чт: 2 задания (практика, код);
- Пт: 1 задание + рефлексия по всем заданиям недели;
- Сб или Вс: 1 задание + code review / демо / работа в команде.

Если вы выпадаете из ритма на 2+ недели — это сигнал пересмотреть нагрузку,
а не «догонять» по ночам. Год выигрывает стабильность, а не рывок.

## Правило «нельзя идти дальше»

Задание считается закрытым, если одновременно выполнены 4 условия:
1. код/артефакт сделан и работает в вашей ИБ;
2. выполнены все пункты Definition of Done из YourTask.txt;
3. заполнена рефлексия `internship/documentation/task_N_description.txt`;
4. изменения закоммичены с понятным сообщением (с task_31 — обязательно).

## Что делать, если застрял

1. 30 минут самостоятельной борьбы: синтакс-помощник, документация, ТЖР, отладчик.
2. Сформулируй вопрос письменно: что делаю, что ожидаю, что получаю, что уже попробовал.
3. Задай вопрос в чат потока / ментору.
4. Если ответ получен — зафиксируй его в рефлексию и в `internship/backlog/` как заметку.

Формулировка вопроса — это отдельный профессиональный навык (task_38, task_98, task_224).
