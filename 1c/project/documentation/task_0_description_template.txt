УСТАРЕЛО: шаблон описания выполненного задания переехал.

Канонический шаблон: internship/documentation/templates/task_N_description.txt
(см. internship/documentation/README.md — «Описание выполненного задания»).

Заполненное описание сохраняйте как internship/documentation/task_N_description.txt
с вашим номером задания (например, task_5_description.txt).

Этот файл оставлен указателем, чтобы старые ссылки не вели на расходящуюся
версию шаблона: раньше здесь лежала сокращённая копия, которая разошлась
с рабочим шаблоном в internship/.
