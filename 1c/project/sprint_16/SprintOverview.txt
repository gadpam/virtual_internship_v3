СПРИНТ 16 · Q2 · Клиенты внешних API по документации поставщика

ЦЕЛЬ СПРИНТА
Научиться работать с чужими API по документации: онлайн-магазин, лояльность, транспортная компания, курсы валют.

РАМКИ
Спринт = одна неделя = 6 заданий: task_91 ... task_96.
Темп: 2 задания в начале недели, 2 в середине, 1 в пятницу, 1 в выходной
+ рефлексия по всем заданиям недели.

ЗАДАНИЯ СПРИНТА
task_91 — Клиент онлайн-магазина: выгрузка каталога и остатков (3 ч)
task_92 — Клиент программы лояльности: баланс, начисление, списание (3 ч)
task_93 — Клиент транспортной компании и rate limiting (3 ч)
task_94 — Курсы валют, справочники и кеширование внешних данных (2 ч)
task_95 — Ошибки партнёра: деградация, очередь, компенсация (3 ч)
task_96 — Контрактные тесты и документация для партнёра (2 ч)

РЕЗУЛЬТАТЫ СПРИНТА (что должно появиться к выходным)
- Реализованы 4 клиента внешних API с ретраями и логированием

- Умеете читать чужую документацию и задавать вопросы поставщику
- Ошибки партнёра не ломают вашу систему
