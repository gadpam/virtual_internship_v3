ЗАДАНИЕ task_94 · спринт 16 · Q2
Тема спринта: Клиенты внешних API по документации поставщика
Курсы валют, справочники и кеширование внешних данных

Оценка времени: 2 ч
Уровень задания: резерв — буфер квартала; при отставании не выполняется

КОНТЕКСТ: зачем это нужно
Часть внешних данных меняется предсказуемо (курсы валют — раз в день)
и нужна почти во всех расчётах. Правильный подход: загрузка по расписанию, хранение
локально, использование локальной копии, а не вызов API на каждый расчёт.

ЗАДАНИЕ: что сделать
1. Реализуйте загрузку курсов валют по расписанию из внешнего источника
   (mock или публичный API) в РС «КурсыВалют».
2. Реализуйте fallback: если источник недоступен, использовать последний известный курс
   и поднять предупреждение.
3. Добавьте проверку аномалий: курс изменился более чем на 30% — требуется подтверждение.
4. Используйте локальные курсы в расчёте суммы документа (доработка из Q1).
5. Опишите: какие ещё справочники стоит загружать локально и почему.

РЕЗУЛЬТАТ (Definition of Done):
- Загрузка по расписанию работает, курсы хранятся локально
- Fallback реализован и проверен на остановленном mock
- Проверка аномалий срабатывает (тест на искусственном скачке)
- Расчёт документа использует локальные курсы

ПОДСКАЗКИ МЕНТОРА:
- Аномалия курса — реальный кейс: опечатка поставщика может изменить цены в 10 раз. Лучше остановить загрузку, чем испортить учёт.
- Локальная копия данных — это не «кэш, который может устареть», а источник для учёта. Разница в ответственности.
