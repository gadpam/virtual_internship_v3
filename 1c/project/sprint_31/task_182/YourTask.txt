ЗАДАНИЕ task_182 · спринт 31 · Q3
Тема спринта: MS SQL Server глазами разработчика 1С
T-SQL для анализа: соединения, окна, CTE, агрегаты

Оценка времени: 3 ч

КОНТЕКСТ: зачем это нужно
Анализ данных в СУБД часто быстрее и гибче, чем в 1С: оконные функции,
CTE, GROUPING SETS. Эти инструменты нужны для расследований («почему цифры не
сходятся») и для подготовки данных перед массовой обработкой.

ЗАДАНИЕ: что сделать
1. Напишите 6 аналитических запросов: топ-N по продажам с долей (оконные),
   динамика по месяцам (LAG), накопительный итог, группировка по нескольким уровням
   (GROUPING SETS), поиск аномалий, сравнение периодов.
2. Используйте CTE для читабельности и сравните производительность с подзапросами.
3. Найдите дубли в данных одним запросом (по бизнес-ключу).
4. Найдите «осиротевшие» записи (строки ТЧ без документа, движения без регистратора).
5. Сохраните запросы в internship/tools/sql/analysis/ с комментариями.

РЕЗУЛЬТАТ (Definition of Done):
- 6 аналитических запросов работают и задокументированы
- Запрос дублей и «сирот» нашёл искусственно созданные проблемы
- CTE vs подзапросы сравнены по времени
- Запросы сохранены в репозитории с комментариями

ПОДСКАЗКИ МЕНТОРА:
- Оконные функции экономят самосоединения: доля, ранг, накопительный итог пишутся в одну строку.
- На больших таблицах добавляйте TOP/ограничения во время разработки: иначе каждый запуск будет стоить минут.
