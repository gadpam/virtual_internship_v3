ЦЕЛЬ СПРИНТА
Сделать интерфейсы, которыми пользуются люди: формы, команды, валидация, сообщения, локализация, зачатки мобильной версии.

РАМКИ
Спринт = одна неделя = 6 заданий: task_37 ... task_42.
Темп: 2 задания в начале недели, 2 в середине, 1 в пятницу, 1 в выходной
+ code review спринта + рефлексия по всем заданиям недели.
Оценка времени ниже — только на сами задания; code review и рефлексия
в неё не входят (см. Roadmap.md, раздел про реальную нагрузку).

task_40 — Локализация: RU/EN и многоязычные данные (2 ч)

Резерв (при отставании не выполняется): —.
