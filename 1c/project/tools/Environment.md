# Окружение стажёра: что ставить и когда

Год работы требует стабильного стенда. Ставьте постепенно: Q1 — минимум,
остальное по мере появления в заданиях. Все версии фиксируйте в
`internship/tools/VERSIONS.md` — «у меня работает» без версий не воспроизводится.

## Q1 (спринты 0–12): минимум для старта

| Инструмент | Версия | Зачем | Комментарий |
|---|---|---|---|
| Платформа 1С:Предприятие 8.3 | 8.3.24+ (актуальная на момент потока) | Основа всего | Учебная версия подходит до Q3; сервер кластера не нужен до task_55 |
| СУБД | PostgreSQL 15+ или MS SQL Server 2019+ | Файловая ИБ не даёт реальной картины | Поднимайте в Docker, а не ставьте на ноутбук |
| 1C:EDT | актуальная под вашу платформу | Проект в Git, валидация, сборка | Можно работать в Конфигураторе, но Git-трек требует EDT или выгрузки в файлы |
| Git + GitHub | 2.40+ | Версионирование, PR, CI | Настройте SSH-ключ и `core.autocrlf=false` |
| Docker Desktop | последняя | СУБД, mock-серверы, позже Python | Проверьте лимит памяти контейнеров: 8 ГБ минимум |
| Postman или Bruno | последняя | Тестирование HTTP-сервисов | С Q2 станет основным инструментом |
| Java (для vanessa-runner/EDT) | 17 или 21 | Запуск инструментов автоматизации | Не путать с Java-треком этого репозитория |
| Node.js | 20 LTS | vanessa-runner, vanessa-automation | Ставится один раз, используется весь год |

## Q2 (спринты 13–25): интеграции

- vanessa-runner (сборка, публикация, тесты) и vanessa-automation (приёмочные сценарии);
- xUnitFor1C или аналогичный фреймворк юнит-тестирования;
- mock-сервер внешнего API (наш `internship/src/mock_shop_api` на Python/FastAPI);
- утилита для XSD/JSON-схем, SOAP UI или просто curl;
- второй экземпляр ИБ (для обменов: RIH ↔ «внешняя система»);
- план обмена и КД 2.0/3.0 (поставляются с платформой/ITS).

## Q3 (спринты 26–38): учёт, СУБД, BI

- MS SQL Server Management Studio (SSMS) или Azure Data Studio; pgAdmin для PostgreSQL;
- учебные базы типовых конфигураций: Бухгалтерия предприятия (БП) и Документооборот (ДО) —
  демо-базы можно создать из шаблонов;
- 1С:Конвертация данных 2 и 3;
- BI-инструмент: Apache Superset в Docker (или любой другой);
- инструмент профилирования: АПК (анализ программы и консоли запросов), консоль кода.

## Q4 (спринты 39–51): AI, мобильность, эксплуатация

- Python 3.11+, uv или pip + venv, VS Code/PyCharm;
- FastAPI, uvicorn, pytest, httpx — всё ставится из `internship/src/ai_service/requirements.txt`;
- векторное хранилище: pgvector (расширение для вашего PostgreSQL) или FAISS;
- доступ к LLM API (любой провайдер по вашему выбору) — ключ хранится только в
  `.env`, который в Git не попадает;
- мобильная платформа 1С (эмулятор/устройство Android);
- nginx + docker-compose для публикации сервиса и CI-контур GitHub Actions.

## Лицензии и законность

Для обучения подходит учебная версия платформы и демо-базы типовых конфигураций.
Коммерческое использование требует лицензий — это ваша ответственность.
В программе не распространяются дистрибутивы 1С и типовые конфигурации:
вы получаете ссылки на официальные источники и инструкции по установке.

## Рекомендуемая конфигурация машины

- 16 ГБ RAM минимум, 32 ГБ комфортно (ИБ + PostgreSQL + Docker + EDT);
- SSD обязателен: ИБ на HDD убьёт мотивацию быстрее, чем любое задание;
- 100 ГБ свободного места;
- два монитора сильно ускоряют работу с EDT и документацией.

## Что делать, если платформы 1С нет вообще

- Начните с официальной учебной версии платформы (скачивается на портале 1С
  после регистрации) — этого достаточно для Q1 и Q2.
- Первые 4 спринта можно пройти в облачной демо-базе, но с task_20 вам
  понадобится своя ИБ: без неё невозможны Git-трек и тесты.
