Уровень задания: ядро — обязательное; без него спринт не закрыт

ЛЕГЕНДА И КОНТЕКСТ: ситуация и зачем это нужно
Классический спор: «1С говорит — сервис виноват; сервис говорит —
запрос кривой». Спор решается не громкостью, а correlationId и пакетом
диагностики. Сегодня процесс совместной отладки договаривается заранее.

Когда «1С говорит, что сервис виноват, а сервис — что 1С», выигрывает тот,
у кого есть логи, идентификаторы запросов и воспроизводимый пример. Процесс совместной
отладки надо договорить заранее.

ТЕОРИЯ: что нужно знать перед выполнением
Сквозной корреляционный идентификатор: 1С генерирует UUID на
логическую операцию, шлёт заголовком, Python-сервис принимает,
логирует в каждую запись и возвращает в ответе. Поиск «что произошло
с операцией X» становится grep по одному значению в двух системах —
минуты вместо часов перебора логов по времени.

Формат обращения в AI-команду фиксирует состав: correlationId,
время и часовой пояс, запрос и ответ (с маскированием ПДн — task_135),
версии обеих сторон, что уже проверено. Обращение без версий
и идентификатора возвращается уточняющими вопросами — это надо
знать и не обижаться.

Пакет диагностики одной кнопкой в 1С собирает перечисленное в
файл/письмо: секретов и открытых ПДн в нём нет по построению.

Оценка экономии времени на учебной отладке — цифра для процесса:
процесс, польза которого не измерена, отменяется первым.

Учебная отладка цифрами: найти запрос без correlationId — 40 минут
по двум логам, с ним — 3 минуты grep. Типичные ошибки: correlationId
генерировать на каждый HTTP-запрос вместо логической операции
(цепочка рвётся); в пакет диагностики складывать токены и ПДн;
формат обращения не версионировать — через полгода он другой,
а история обращений врёт.

Проверка понимания: найдите одну операцию по correlationId в логах
обеих систем за три минуты и покажите цепочку. Если поиск требует
знать точное время и перебирать окна логов, идентификатор не
проходит сквозь системы, а существует только в заголовке запроса.

CorrelationId генерируется на логическую операцию, а не на HTTP
вызов: цепочка из трёх вызовов несёт один идентификатор, иначе
след рвётся на втором звене. Пакет диагностики собирается без
секретов и открытых ПДн (task_135): пакет, который нельзя
переслать, не является пакетом диагностики. Формат обращения
версионируется: обращение полугодовой давности обязано читаться
по своей версии формата. Экономия измеряется на учебной отладке
цифрой минут: процесс без измеренной пользы отменят первым.

4. Проведите учебную совместную отладку с ментором/коллегой по описанному процессу.
5. Оцените: сколько времени сэкономили корреляционный ID и пакет диагностики.
