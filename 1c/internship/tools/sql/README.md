# SQL-скрипты стенда (спринты 31–36: task_181–198, task_205–216–204)

Работа с MS SQL Server под 1С: исследование, аналитика, обслуживание, витрины,
ETL, диагностика, резервные копии, выгрузка. Диалект — T-SQL (MS SQL Server 2019+);
там, где поведение отличается от PostgreSQL, это отмечено в комментариях.

## Правила работы с СУБД (обязательны к соблюдению)

1. **Продакшн — только чтение.** Все скрипты, которые что-то меняют, начинаются
   с `SET TRANSACTION ISOLATION LEVEL` и блока `-- DRY RUN`. Реальное выполнение —
   после снятия комментария и только на тестовом стенде (task_183).
2. **Никаких `SELECT *` на больших таблицах без `TOP`.** Одна невнимательная
   выборка из `_InfoR12345` на 40 млн строк кладёт сервер.
3. **Каждый скрипт имеет шапку**: назначение, автор, дата, задание, ожидаемое время,
   риски, как отменить.
4. **Изменения — в транзакции с журналом**: `BEGIN TRAN` / `COMMIT` / `ROLLBACK`
   и запись результата в служебную таблицу.
5. **Не трогайте таблицы 1С напрямую на запись.** Правка данных в `_Reference*`,
   `_Document*` минуя 1С ломает ссылочную целостность и лишает поддержки.
   Исключение — учебные задания, где это разрешено явно и на копии базы.
6. **Время выполнения фиксируйте.** `SET STATISTICS TIME, IO ON` — первый шаг
   любого расследования (task_187).
