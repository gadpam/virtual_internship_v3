# Аналитика T-SQL (task_182, task_190)

Ответы на вопросы «сколько», «как растёт», «где узкое место» — средствами SQL, а не
отчётов 1С. Отчёт 1С отвечает на вопрос бизнеса; SQL отвечает на вопрос инженера.

| Файл | Вопрос, на который отвечает |
|---|---|
| `010_growth_dynamics.sql` | как растёт объём данных по месяцам и что будет через 12 месяцев |
| `020_hot_tables.sql` | какие таблицы читают и пишут чаще всего |
| `030_safe_update_template.sql` | шаблон безопасного изменения данных (dry run, транзакция, журнал) |

Отчёт по заданию должен содержать: числа, вывод и **одно решение** (например
«архивировать регистр X за периоды до 2024 года, ожидаемая экономия 18 ГБ»).
Решение без чисел — гипотеза; числа без решения — справка. Ни то, ни другое
в работе не принимается.
