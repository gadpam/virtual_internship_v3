# Исследование: как 1С хранит данные в СУБД

Цель задания task_181 — перестать воспринимать СУБД как «чёрный ящик под 1С».
После этих скриптов вы знаете: какие таблицы относятся к какому объекту
метаданных, чем справочник отличается от регистра по физической структуре,
где живут большие данные и почему.

Порядок выполнения: по номерам файлов. Каждый скрипт — только чтение.

| Файл | Что показывает |
|---|---|
| `010_database_overview.sql` | база, файлы, размеры, режим восстановления, collation |
| `020_1c_table_map.sql` | соответствие таблиц 1С объектам метаданных |
| `030_top_tables_by_size.sql` | топ таблиц по объёму и числу строк |
| `040_index_inventory.sql` | какие индексы есть у ключевых таблиц |

Что положить в отчёт по заданию:
1. Схема «объект метаданных → таблица(ы) СУБД» для 5 своих объектов.
2. Топ-10 таблиц по размеру с гипотезой, почему они большие.
3. Два наблюдения, которые вы не ожидали увидеть.
