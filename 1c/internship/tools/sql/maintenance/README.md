# Обслуживание СУБД (task_195, task_185)

Регламентные операции, от которых зависит производительность 1С: перестроение
индексов, обновление статистики, контроль tempdb и журнала транзакций,
обслуживание самой информационной базы (ТИИ).

| Файл | Что делает |
|---|---|
| `010_index_fragmentation.sql` | фрагментация индексов и решение REBUILD/REORGANIZE |
| `020_maintenance_plan.sql` | шаблон еженедельного плана обслуживания с журналом |
| `030_tempdb_and_log.sql` | диагностика tempdb и журнала транзакций |

## Пороговые значения (учебный стандарт RIH)

| Показатель | Действие |
|---|---|
| фрагментация < 5% | ничего не делаем |
| 5–30% | `ALTER INDEX ... REORGANIZE` |
| > 30% | `ALTER INDEX ... REBUILD` с `ONLINE = ON` (Enterprise) |
| статистика старше 7 дней или `modification_counter` > 10% строк | `UPDATE STATISTICS` |
| журнал транзакций > 70% | проверить бэкапы LOG, активную транзакцию |
| tempdb > 80% | найти запрос с большой сортировкой/хешированием |

Обслуживание всегда — в окно низкой нагрузки и всегда с журналом «что сделано,
сколько длилось, какой эффект». Иначе через месяц никто не вспомнит, почему
стало быстрее (или медленнее).
