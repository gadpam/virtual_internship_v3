# tools/sql/plans/

Фактические планы выполнения запросов (.sqlplan из SSMS/ADS или снимки
из pg_stat_statements/EXPLAIN ANALYZE для PostgreSQL-контура).

Сюда складываются планы из task_187 (три запроса: быстрый/средний/тяжёлый)
и пары «план до / план после» из task_188–190. Имя файла — по шаблону
`<запрос>_до.sqlplan`, `<запрос>_после.sqlplan`: сохранённый план —
артефакт разбора, прикладывается к задаче оптимизации (через квартал
он — вход регресса производительности).

План сравнивается для того же запроса с теми же параметрами:
план с другими параметрами — другой диагноз.
