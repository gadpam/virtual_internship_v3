# Самоподписанные сертификаты для учебного стенда

Файлы `mock.crt` и `mock.key` **не хранятся в Git** — они генерируются локально
скриптом `generate.sh` и добавлены в `.gitignore`. Это сделано намеренно: привычка
класть ключи в репозиторий — самая частая причина утечек (task_134, task_133, task_260).

```bash
cd 1c/internship/tools/nginx/certs
./generate.sh
```

Если HTTPS на учебном стенде не нужен, закомментируйте блок `server { listen 443 ssl; }`
в `nginx/nginx.conf` — тогда пустой каталог сертификатов не помешает запуску.
