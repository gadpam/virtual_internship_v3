# CI для сценариев 1С (task_53)

## Честный статус

Платформа 1С в CI недоступна (лицензии и дистрибутив не могут лежать
в публичном раннере). Поэтому сценарии vanessa (`internship/tests/features/`)
в CI **не запускаются**, а шаг фиксируется пропуском с причиной — не
красной ложью и не зелёной. Локальный прогон: vanessa-runner на стенде
с платформой; до её появления числа сценариев исполняет зеркальный
раннер `src/scripts/run_all_checks.py` (checks_posting/checks_stock_control
покрывают приёмочный и негативный сценарии цифрами).

## Как включить, когда платформа появится

1. Раннер с EDT/платформой и лицензией (self-hosted).
2. Шаг: собрать конфигурацию из исходников, развернуть тестовую ИБ,
   прогнать `vanessa-runner run` по `tests/features/`.
3. Отчёт прогона (junit) приложить к запуску; падение сценария = красный шаг.

## Что гоняется в CI уже сейчас

- Линтер BSL и проверки исходников (task_12) — без платформы.
- Зеркальные проверки (run_all_checks.py) — алгоритмы и SQL-аналоги.
