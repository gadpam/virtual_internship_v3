# Сценарии сквозного прогона (Gherkin, `# language: ru`)

Сценарии описывают **поведение системы глазами пользователя**, а не реализацию.
Прогоняются vanessa-runner (task_53) и используются как золотой путь года
(task_302) и полный регресс (task_303).

| Файл | Сценарий |
|---|---|
| `golden_path.feature` | день из жизни холдинга: заказ → резерв → отгрузка → лояльность → проводки |
| `integration_errors.feature` | негативная ветка: сбой партнёра, очередь, DLQ, инцидент в трекере, разбор |
| `reports_smoke.feature` | дымовой прогон ключевых отчётов (task_142) |

## Правила написания

1. Первая строка файла — `# language: ru`.
2. Один сценарий = одна бизнес-история; не более 15 шагов, иначе делите.
3. Никаких GUID и «внутренностей»: шаги формулируются в терминах интерфейса и данных.
4. Предусловие (`Дано`) готовит данные, а не проверяет их.
5. Проверки — только через `Тогда`; «просто открыли форму» проверкой не считается.
6. Сценарий должен быть **изолирован**: прогон в любом порядке даёт тот же результат.
