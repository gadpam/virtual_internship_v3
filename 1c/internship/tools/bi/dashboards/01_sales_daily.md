# Дашборд «Продажи по дням»

**Зритель:** коммерческий директор, аналитик розницы.
**Вопрос:** где выручка проседает относительно плана и предыдущего периода и что
за этим стоит — трафик, средний чек или отсутствие товара.
**Источник:** `marts.v_sales_daily` (словарь метрик M-001…M-004, M-010).
**Обновление:** T+1 до 06:00; при нарушении — баннер красным (task_210).

## Панели

| № | Панель | Тип | Метрика / формула | Фильтр |
|---|---|---|---|---|
| 0 | Свежесть данных | Text/Markdown | `marts.v_freshness` по витрине `fact_sales` | — |
| 1 | Выручка за период | Big Number + дельта | M-001 `SUM(revenue)` vs предыдущий период | период, город |
| 2 | Валовая прибыль | Big Number + дельта | M-002 `SUM(revenue) - SUM(cost)` | период, город |
| 3 | Маржинальность | Gauge | M-003, порог 18% | период |
| 4 | Динамика выручки | Time-series (линия + столбцы) | M-001 по дням, линия — скользящее среднее 7 дней | период |
| 5 | Выручка по магазинам | Bar chart, сортировка по убыванию | M-001 по `store_name` | город, канал |
| 6 | Структура каналов | Pie/Donut | M-001 по `channel` | период |
| 7 | Топ-20 товаров | Table с heatmap по выручке | M-001, M-003 по категории | период |
| 8 | Отклонение от плана план-факт | Bar chart | `(fact - plan) / plan`, план из `staging.sales_plan` | период, магазин |
| 9 | Аномальные дни | Table | `marts.v_sales_anomalies` | — |

## Drill-down

Клик по магазину (панель 5) → фильтрует панели 4, 7, 8 этим магазином.
Клик по дню (панель 4) → открывает детализацию по чекам в `marts.v_sales_masked`
(без прямых идентификаторов, task_208).

## Что дашборд НЕ показывает и почему

- **Прибыль по торговым точкам после распределения затрат** — нет согласованной
  методики распределения; метрика появится после записи в словарь (task_206).
- **Данные по клиентам (персональные)** — доступны только агрегированно и только
  роли с основанием (task_208, task_291).

## Проверка приёмки

1. Выручка за вчера совпадает с отчётом 1С «Продажи по магазинам» с точностью до
   копейки. Расхождение → инцидент качества данных, а не «округление».
2. При выборе периода без данных дашборд показывает пустое состояние, а не ошибку.
3. Все панели реагируют на фильтр города.
4. Время открытия дашборда ≤ 5 секунд на учебном объёме (90 дней × 5 магазинов).
