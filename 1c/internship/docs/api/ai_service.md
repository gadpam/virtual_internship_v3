# AI-сервис RAG · endpoints · task_231, task_241

Сервис: `src/ai_service` · порт `8010` · через nginx `/ai/` (таймаут 120 с).
Авторизация: `X-Api-Key` (`AI_SERVICE_API_KEY`).

## Методы

### `GET /health`

`{ "status": "ok", "service": "rih_ai_service", "index": {...} }` — живость и
состояние индекса. Без авторизации: используется healthcheck.

### `GET /api/v1/stats`

Состояние корпуса и индекса: число документов, чанков, версия индекса, время
последней сборки, параметры поиска (`top_k`, `min_score`).

### `POST /api/v1/search` — поиск по корпусу

```json
{ "query": "как оформить возврат от покупателя", "topK": 5, "filters": {} }
```

Ответ: найденные фрагменты с `score`, `document`, `section`, `chunkId`, `text`.
Если лучший результат ниже `SEARCH_MIN_SCORE` (0,35 по умолчанию) — возвращается
пустой набор: лучше «не нашёл», чем неправдоподобный ответ (task_243).

### `POST /api/v1/ask` — вопрос с ответом

Ответ `Answer`: `answer`, `citations[]` (источник + фрагмент), `refused` (bool),
`confidence`, `incidentId`. При `refused: true` текста ответа нет — сервис честно
говорит «не знаю» и предлагает, где искать (task_242, task_243).

### `POST /api/v1/index/rebuild` — перестроение индекса

Перечитывает `KNOWLEDGE_BASE_DIR` (`internship/docs/knowledge_base`), пересобирает
чанки и векторы, увеличивает версию индекса (task_240). Операция дорогая: вызывается
регламентным заданием или вручную после обновления корпуса, не по каждому запросу.

## Соглашения

* ошибки — единый формат (`error_format.md`);
* `incidentId` обязателен в каждом ответе: по нему ответ связывается с чанками,
  версией индекса и журналом;
* таймаут клиента 1С — 120 с (nginx `/ai/`), повтор **не выполняется**: запрос
  к LLM недёшев, при таймауте показываем деградацию «ассистент временно недоступен»
  (task_250);
* права и лимиты использования — task_249: кто может спрашивать, сколько запросов,
  что пишется в аудит.

## Оценка качества

Метрики поиска (`evaluation/metrics.py`): hit@1, hit@5, MRR, recall@10 на наборе
эталонных вопросов `evaluation/golden_questions.json`. Прогон:

```bash
cd 1c/internship/src/ai_service
python3 -m evaluation.run_evaluation
```

Пороги и порядок разбора расхождений — `src/ai_service/evaluation/README.md`
(task_238, task_244).
