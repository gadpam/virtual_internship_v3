# Руководство партнёра RIH API (task_96)

Версия контракта: 1.0.0 (`openapi.yaml`). Этот документ — внешний:
он описывает только то, на что партнёр может опереться. Внутренние
детали реализации сюда не попадают и партнёра не касаются.

## 1. Как подключиться

1. Получите ключ доступа у команды RIH (контакт — раздел 8).
2. Проверьте доступность: `GET /hs/rih/health` — ключ не нужен.
3. Пройдите примеры из песочницы (раздел 7) на тестовом контуре.
4. Согласуйте с нами окна и объёмы первой боевой выгрузки.

## 2. Авторизация

Каждый запрос, кроме `/health`, несёт заголовок `X-Api-Key`.
Ключ привязан к вашей системе: утечка ключа одной системы не открывает
остальные. Нет ключа — `401 RIH-401`; ключ отозван — тот же ответ
(мы не подсказываем, существует ли ключ). Ротация — по запросу,
со старым ключом даётся 24 часа перекрытия.

## 3. Операции

| Операция | Метод и путь | Идемпотентность |
|---|---|---|
| Каталог товаров | `GET /hs/rih/products?limit=&offset=` | безопасный повтор |
| Остатки | `GET /hs/rih/stock` | безопасный повтор |
| Приём заказа | `POST /hs/rih/orders` + заголовок `Idempotency-Key` | повтор тем же ключом возвращает первый результат |
| Статус заказа | `GET /hs/rih/orders/{externalId}` | безопасный повтор |
| Смена статуса | `PUT /hs/rih/orders/{externalId}/status` | повтор тем же телом безвреден |

Пагинация каталога: `limit` 1–500, сортировка стабильная — страница
не «плывёт» между запросами.

## 4. Формат ошибок

Все ошибки — одна форма: `{code, message, details, incidentId, timestamp}`,
коды — справочник `error_format.md` (RIH-400 … RIH-504). По
`incidentId` поддержка найдёт ваш вызов в нашем журнале за секунды:
указывайте его в обращениях.

## 5. Повторы и лимиты

Временные сбои (`RIH-429`, `RIH-502`, `RIH-504`, сеть) повторяйте
с экспоненциальной паузой 1–2–4–8 секунд и не более 5 попыток.
`Retry-After` при 429 обязателен к исполнению. Постоянные ошибки
(`RIH-422`) не повторяйте: сначала исправьте данные.

## 6. SLA и окна

Доступность контура — 99.5% в месяц; плановые окна — воскресенье
02:00–04:00, предупреждаем за 3 дня. Ответ каталога — до 500 мс
на страницу в 500 позиций. Инциденты P1 подтверждаем за 30 минут.

## 7. Песочница

`docs/api/sandbox/` — запускаемые примеры curl против учебного
контура: здоровье, каталог, заказ, повтор заказа, ошибка формата.
ИБ 1С для песочницы не нужна.

## 8. Контакты и изменения контракта

Интеграции RIH: integrations@example.com, канал инцидентов —
по incidentId из ответа. Контракт версионируется в URL и OpenAPI:
ломающие изменения — новая мажорная версия, старая живёт 90 дней
после объявления.
