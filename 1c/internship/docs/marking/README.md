# Маркировка и прослеживаемость

Материалы к task_116 (учёт кодов маркировки) и task_256 (сканирование на кассе/ТСД).

## Базовые понятия

- **Код маркировки** — уникальный идентификатор единицы товара (или агрегата-упаковки).
  Код проходит путь: введён в оборот → в наличии → выбыл (продажа, списание) / возвращён.
- **Агрегат** — код упаковки (короб, палета), содержащий коды единиц: движение
  родителя двигает детей, раскрытие агрегата — явная операция приёмки/перемещения.
- **Инвариант учёта**: количество товара на остатках = число кодов этого товара
  в статусе «в наличии». Расхождение — инцидент, ловится отчётом сверки (task_116, шаг 4).

## Где живёт модель

- Регистр сведений «КодыМаркировки» (код, номенклатура, статус, документ-источник, дата)
  создаётся в task_116; диаграмма состояний кода — `documentation/architecture/marking_model.md`.
- Статусы кода — конечный автомат: запрещённые переходы (например, продажа уже
  выбывшего кода) блокируются в одном месте обработки кодов, а не проверками по документам.
- Объёмы кодов считаются заранее: миллион кодов — отдельная таблица, индексы и архив
  (task_215), а не строковое поле в документе.
