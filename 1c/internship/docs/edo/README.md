# ЭДО: образцы и требования

Материалы к task_90 (обзор ЭДО) и task_115 (приёмник документов ЭДО).

| Файл | Что это |
|---|---|
| `samples/upd_sample.xml` | Учебный образец УПД (СЧФДОП): 2 товарные строки, НДС 20% и 10%, итоги 16900.00 / налог 2560.00. Структура упрощена относительно формата оператора; подпись опущена |

Правила работы с образцами:
- принятый оригинал неизменяем: приёмник хранит исходный XML как есть (task_115, шаг 4);
- документы с ошибками сопоставления контрагента/номенклатуры уходят в «карантин»,
  а не отбрасываются молча;
- свои образцы для тестов кладите рядом, с суффиксом причины: `upd_bad_signature.xml`, `upd_unknown_sku.xml`.
