# Права и контроль исполнения в документообороте (task_168)

## Роли

| Роль | Видит | Может менять |
|---|---|---|
| Исполнитель | свои задачи и документы своих процессов | решение по своей задаче |
| Руководитель подразделения | документы своего подразделения | задачи своих этапов, эскалации |
| Юрист | договоры всех подразделений | свои этапы согласования |
| Администратор | настройки процессов, реестр доработок | маршруты, лимиты, роли |
| Технический пользователь интеграции | — (интерактивного входа нет) | только API обмена состояниями |

## Ограничение по подразделениям

Три оси прав: роль × вид документа × стадия процесса, плюс
подразделение владельца. Ограничение применяется на уровне
записей: чужое подразделение не видно в списках и отчётах,
а не «видно, но не открывается». Прямая ссылка на чужой
документ — тот же запрет, ссылка не обход прав.

## Проверка четырьмя пользователями

| Пользователь | Список договоров | Чужое подразделение | Прямая ссылка | Запись |
|---|---|---|---|---|
| Юрист | все подразделения | видит договоры, не приказы по персоналу | своя область открывается | только свой этап |
| Руководитель Север | только Север | список пуст | запрет | свои задачи |
| Исполнитель | только свои задачи | не видит списков подразделений | запрет | решение по задаче |
| Интеграция (тех.) | интерактивно недоступно | — | — | API состояний только |

## Отчёты

- «Контроль исполнения процессов» (…183): где документы, кто
  держит, возраст по этапам, просроченные — руководителю до
  срыва срока, а не после.
- «Нагрузка на согласующих» (…184): задачи и время с учётом
  отпусков и делегирования. Назначение — баланс маршрутов
  (этап перегруженного — кандидат на параллельность или
  второго исполнителя), а не рейтинг людей: отчёт без отпусков
  врёт, и врать он будет ровно про отсутствующих.
