# Рабочее место исполнителя процессов RIH (task_172)

## Замер сценария

«Открыть → понять, что хотят → закрыть задачу» на списке
60 задач (зеркало; замер «до» — до улучшений, методика task_165):

| | Было | Стало |
|---|---|---|
| Список | все задачи процессов подряд | мои по роли, просроченное красным сверху |
| Контекст | поиск сообщения обмена по базе, ~1:20 | из задачи в один клик, ~0:05 |
| Закрытие | открыть карточку, заполнить, вернуться | быстрое действие с результатом из строки, ~0:25 |
| **Итого** | **2:30** | **0:40** |

## Состав места

- **Фильтры**: процесс, срок (просрочено/сегодня/неделя),
  приоритет, статус. Сортировка — срок, не дата создания.
- **Счётчики** «всего / просрочено / сегодня» одним запросом
  суммарно: цифра отдельным запросом на каждую делает открытие
  формы дольше самой задачи.
- **Индикаторы**: просроченное красным видно без открытия
  карточки — цвет строки меняет поведение сильнее напоминаний.
- **Быстрые действия**: взять в работу; выполнить (результат
  обязателен там, где его ждёт следующий этап); отложить —
  только с причиной и новой датой; делегировать; вернуть
  инициатору. Каждое фиксирует автора и время: история задачи —
  вход аналитики task_173.
- **Контекст в один клик**: сообщение обмена, документ, заказ
  открываются прямо из строки задачи.

Откладывание без причины запрещено полем формы: десяток
молча отложенных задач руководитель увидит в аналитике
процессов как этап-чёрную дыру, а не сюрпризом на планёрке.
