# Интеграция процессов RIH с ДО и внешними трекерами (task_174)

## Источник истины по полям

| Поле | Владелец | Остальные системы |
|---|---|---|
| Статус согласования договора | ДО | RIH — read-only копия с датой синхронизации |
| Техническое состояние разбора (этап, результат) | RIH | трекер показывает ссылку на процесс |
| Статус разработки/инцидента в трекере | трекер | RIH — копия и ссылка, не вторая переписка |
| Комментарии и история работы | система, где работает человек | соседи получают состояние и ссылку, не копии переписки |
| Срок задачи (due) | система-владелец задачи | синхронизируется значением, не пересчитывается чужой логикой |

Поле без владельца — гарантированное расхождение через месяц;
«последняя запись побеждает» по времени разных систем источником
истины не является.

## Соответствие состояний (трекер)

| RIH процесс | Трекер |
|---|---|
| Новая | new |
| ВРаботе | in_progress |
| ОжидаетПартнёра | blocked |
| Решена | resolved |
| Закрыта | closed |

Переходы проверяет трекер: незаконный — 422 с разрешёнными;
клиент обрабатывает ответ, а не навязывает статус.

## Правила обмена

- Одна задача — одна система-владелец: вторая хранит ссылку
  и статус-копию. Полная двусторонняя синхронизация «всего»
  плодит конфликты (урок task_255) — запрещена.
- Создание — с внешним ключом (external_ref): повторная
  синхронизация возвращает ту же задачу.
- Синхронизация журналируется (task_84): расхождение списков
  задач находится сверкой, а не вопросом «а где задача».
