# documentation/docflow/

Документооборот: процессы, маршруты, интеграция с RIH.

| Файл | Что это | Задание |
|---|---|---|
| `processes.md` | модель ДО и 5 процессов холдинга, маршрут одного процесса (state machine) | task_163 |
| `approval_process.md` | настройка согласования: этапы, сроки, эскалация, обоснование порядка | task_164 |
| `workspace.md` | рабочее место исполнителя и замеры сценария «найти → согласовать» до/после | task_165 |
| `integration_doh_rih.md` | контракт ДО ↔ RIH и таблица соответствия состояний | task_166 |

Проектирование начинается от конечного состояния («договор подписан»),
а этапы выводятся назад. Исполнители — роли, а не фамилии.
