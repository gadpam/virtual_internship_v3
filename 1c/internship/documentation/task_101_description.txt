     1,2,4,5 приняты, потеря 3 обнаружена контролем номеров сама;

     закрыла дырку, повторная сверка — ноль расхождений.
   - Процедура восстановления дописана в troubleshooting/exchange.md:
     стоп отправки, диапазон по номерам, переотправка, сверка до нуля;
     «переслать всё с нуля» без диагностики запрещено.
