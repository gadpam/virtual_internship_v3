     справочники применяют последнее по моменту, статусы идут
     по машине состояний (consistency_model.md).
   - Сценарии проверены зеркалом (checks_event_order.py): дубль
     применён один раз; событие не по порядку проиграло (остаток

   - Сверка: искусственное расхождение витрины (SKU-2: 5 против 7)
     найдено и исправлено автоматически от master RIH.
   - Модель согласованности: eventual — витрина, статусы, курсы;
     строгая недопустима для резерва, баллов при списании и денег.
