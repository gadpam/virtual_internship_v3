# Обмен RIH → БП: поступление товаров (task_103)

Приёмник учебного обмена — вторая база RIH в роли БП (полноценная БП —
task_160, Q3). Документ RIH «ПоступлениеТоваров» становится в приёмнике
«Поступление (акт, накладная)» с аналитикой бухгалтерского учёта.

## Подстановка аналитики

| Приёмник (БП) | Источник | Правило |
|---|---|---|
| Организация | RIH.Организация (строка, долг task_152) | Сопоставление по наименованию в справочнике соответствий |
| Склад | RIH.Склад | По наименованию, master — RIH |
| Номенклатура | RIH.Номенклатура | По артикулу (цепочка task_98) |
| Контрагент | RIH.Поставщик | По УНП/наименованию из соответствий |
| Договор | — (в RIH нет) | Договор по умолчанию «Основной» для пары организация+контрагент; отсутствие пары — ошибка обмена, а не тихий NULL |

## 5 расхождений моделей и решения

1. **Организация строкой против справочника.** У нас долг модели до
   task_152; обмен сопоставляет по наименованию и падает на незнакомой
   организации — молчаливое создание организации в БП запрещено.
2. **Договора нет в RIH.** БП требует договор для проводок; подставляем
   основной договор пары из соответствий, заведение пары — действие
   бухгалтера, а не обмена.
3. **Счета учёта.** В RIH счетов нет (Q1 без бухгалтерии): счёт 41/10
   приёмник определяет по виду номенклатуры своим правилом БП — RIH
   вид не диктует.
4. **НДС.** RIH ведёт цены «как пришли»; ставка НДС — аналитика БП
   по номенклатуре приёмника. Обмен ставку не везёт, чтобы не плодить
   два источника налоговой истины.
5. **Момент признания.** RIH проводит поступление движением остатков;
   БП — проводками на дату документа. Дата берётся из источника,
   перепроведения задним числом в закрытый период БП отклоняет —
   обмен получает ошибку и ставит документ в очередь разбора, а не
   «сдвигает дату».

Проверка учебного обмена: суммы и количество строк приёмника сходятся
с источником построчно; движения остатков приёмника повторяют источник.
