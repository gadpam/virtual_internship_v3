# Регламент обмена RIH ↔ онлайн-магазин (task_108)

## Состав и расписание

| Поток | Направление | Расписание | Объём |
|---|---|---|---|
| Товары и цены (дельта) | RIH → магазин | каждые 15 минут | пакеты по 500 |
| Остатки | RIH → магазин | каждые 15 минут, срез на момент | по складам магазина |
| Заказы | магазин → RIH | непрерывно (HTTP) | по одному, ключ идемпотентности |
| Статусы заказов | RIH → магазин | по событию смены статуса | по одному |

Окно полной сверки: воскресенье 03:00 — полная выгрузка каталога
и сверка остатков отчётом расхождений (task_101).

## SLA

- Дельта товаров видна в магазине не позже 30 минут после изменения.
- Приём заказа подтверждается за 2 секунды (p95).
- Доступность контура RIH: 99.5% в месяц; плановые окна —
  воскресенье 02:00–04:00 с предупреждением за 3 дня.

## Ответственные и эскалация

| Роль | Кто | Отвечает за |
|---|---|---|
| Владелец обмена | Интегратор RIH | регламент, версии, мониторинг |
| Оператор очереди | Дежурный поддержки | сообщения «Ошибка», ручной разбор |
| Партнёр | Команда магазина | свой контур, ключи, лимиты приёма |

Эскалация: P1 (обмен стоит > 1 часа) — владелец + дежурный, 30 минут
на подтверждение; P2 (ошибки растут, обмен идёт) — 4 часа; P3 —
следующий рабочий день.

## Изменение контракта

1. Предложение — правкой OpenAPI и partner_guide с новой версией.
2. Согласование обеих сторон: минимум 10 рабочих дней до включения.
3. Тест: контрактные тесты task_96 на стенде обеих сторон.
4. Включение по регламенту версий task_104: приёмник первым.

## Инциденты

| Тип | Критичность | Реакция | Шаблон сообщения |
|---|---|---|---|
| Партнёр недоступен | P2 (P1 после часа) | Очередь копит, алерт оператору | «Обмен магазин: недоступность с HH:MM, накоплено N сообщений, данные не теряются» |
| Ошибки валидации растут | P2 | Смотреть rejected поименно (task_91) | «Обмен магазин: rejected вырос до N/час, примеры SKU в журнале» |
| Расхождения сверки | P2 | Процедура task_101 | «Сверка магазин: расхождений N, отчёт приложен» |
| Конфликт версий | P1 | Регламент task_104 | «Обмен магазин: версия формата X не принимается, обновление приёмника по регламенту» |
