# documentation/requirements/functional/

Функциональные требования: интервью, критерии приёмки, прототипы.

Формат требования: ID / требование / критерий приёмки («отчёт за месяц
совпадает с витриной до копейки и строится ≤ 5 с на стенде»), а не
«сделайте удобно». Прототип с выдуманными числами согласовывается до
разработки: реальные цифры уводят совещание в выяснение цифр вместо формы
(task_180).

Сюда же складываются учебные интервью (формат task_29: вопрос, зачем,
что будет, если ответ другой) и чек-листы приёмки по критериям.
