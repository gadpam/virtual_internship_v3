     HTTP-шлюз; рождение события привязано к outbox task_95 — событие

   - Зеркало (checks_broker.py): exchange разносит по routing key
     в 2 очереди; ack только после обработки; временная ошибка —

     и сравнение по 6 критериям. Правило: брокер — события многим
     потребителям, очередь в базе — гарантированная доставка из
     транзакции; между ними мост outbox, а не спор.
