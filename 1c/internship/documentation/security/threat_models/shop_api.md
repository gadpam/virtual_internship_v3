# Модель угроз: HTTP API магазина (входящие заказы)

## Активы
Приём заказов (целостность и неотказуемость), каталог и цены,
ключи/токены клиентов, доступность сервиса приёма.

## Акторы
Внешний атакующий без ключа; партнёр по ошибке (сломанный ретрай,
часы враскоряку); свой сотрудник с лишними правами.

## Угрозы и меры
| Угроза | Мера | Где |
|---|---|---|
| Подбор ключа/токена | единая точка проверки, блокировка перебора, частота выдачи токенов | task_93, task_133, F-4 |
| Огромный payload, пачка-монстр | лимит тела до чтения (1 МБ), лимит элементов 500 | task_136 |
| Флуд и slowloris | rate limit по клиенту, таймаут приёма, лимит соединений | task_136 |
| Дубли заказов ретраями партнёра | идемпотентность по внешнему идентификатору | task_83 |
| ПДн в журнале разбора | санитайзер единой точки записи, маски | task_135 |
| Разведка по метрикам | снимок не анонимен (SEC-1) | task_138 |

## Остаточный риск
Rate limit боевого контура — по журналу/публикации, не в памяти
процесса (SEC-5). Принял: владелец интеграций RIH, пересмотр —
к выводу сервиса наружу, срок — до первого внешнего адреса.
