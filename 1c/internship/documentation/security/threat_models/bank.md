# Модель угроз: банковский шлюз (SOAP, платежи)

## Активы
Деньги: платёжные поручения и их статусы; логин/пароль шлюза;
курсы валют, от которых зависят цены.

## Акторы
Внешний атакующий у контура банка; партнёр с неопределённым
исходом («платёж ушёл или нет»); свой сотрудник с доступом
к константе пароля.

## Угрозы и меры
| Угроза | Мера | Где |
|---|---|---|
| Секрет банка в коде клиента | константы контура из хранилища, доступ по роли | task_134 |
| Двойной платёж после таймаута | неопределённость разрешается тем же ExternalId: статус, а не новый платёж | task_127 |
| Ответ «успех» на неизвестный статус | неизвестный статус — RIH-502, а не «Принято» | ревью sprint_20 |
| Курсы недоступны — цены встали | последний известный курс с датой; старше 7 дней — стоп | task_131 |
| Медленный банк держит сеансы | таймауты по операциям (5/10/20 с) | task_127 |
| Платежи и ПДн плательщика в логах | журнал без payload, маски, срок 90 дней | task_84, task_135 |

## Остаточный риск
SOAP-контур не имеет подписи сообщений: целостность держится
на транспорте стенда и ExternalId. Принял: владелец банковских
интеграций; пересмотр — при боевом подключении банка, вместе
с требованием подписи из его регламента.
