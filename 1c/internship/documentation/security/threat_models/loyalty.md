# Модель угроз: программа лояльности (исходящая интеграция)

## Активы
Баллы клиентов (это деньги), номера карт и телефоны (ПДн),
ключ контура лояльности, доступность кассы без бонусов.

## Акторы
Внешний атакующий, укравший ключ контура; партнёр, отвечающий
ошибками и задержками; сотрудник, смотрящий чужие карты.

## Угрозы и меры
| Угроза | Мера | Где |
|---|---|---|
| Кража ключа контура | ключ вне кода, ротация, хеши секретов клиентов | task_134, task_133 |
| Двойное начисление повтором | ключ идемпотентности операции, 409 на двойное сторно | task_130 |
| Партнёр лежит — касса встала | предохранитель, деградация «продажа без бонусов» с отложенным начислением | task_129, task_131 |
| Телефоны и карты в логах | реестр ПДн, маски единым модулем, санитайзер журнала | task_135 |
| Сотрудник смотрит ПДн «просто так» | полный показ по роли + событие аудита pdn_view | task_135, task_137 |
| Запрос субъекта на удаление | обезличивание с сохранением учётных фактов | task_135 |
