# Чек-лист безопасности интеграций RIH

Проходит каждый PR с интеграциями (стыковка с ревью task_67
и Definition of Done). Каждый пункт — «да / нет / неприменимо»
и способ проверки; пункт без способа проверки не пункт,
а пожелание. Родился из task_133–137 и инцидентов спринта;
обновляется каждым инцидентом безопасности (task_294).

| № | Пункт | Как проверить |
|---|---|---|
| 1 | Аутентификация — первым блоком обработчика, единая точка | поиском по обработчикам: проверка до чтения тела |
| 2 | Токены короткоживущие, отзыв работает, в базе только хеши | checks_tokens: отозванный и истёкший — 401 |
| 3 | Секреты вне кода и репозитория (контур/окружение/CI-secret) | сканер секретов зелёный; `git log -S` по форматам |
| 4 | Ротация секретов без простоя (окно grace) описана и проверена | сценарий ротации на стенде |
| 5 | ПДн в логах замаскированы, payload целиком не пишется | поиск шаблонов телефонов/карт по журналу — ноль |
| 6 | Маскирование — один общий модуль, не «где вспомнили» | поиском: маски вне РИХ_ПерсональныеДанные отсутствуют |
| 7 | Полный показ ПДн — по отдельной роли и в аудит | событие pdn_view на каждый полный показ |
| 8 | Лимит тела запроса проверяется до чтения (по Content-Length) | запрос с заголовком 50 МБ — 413 без тела |
| 9 | Лимиты массива, глубины и пагинации на границе | пачка сверх лимита — 422 |
| 10 | Rate limit по клиенту; перебор ключей блокируется | флуд — 429; журнал попыток растёт |
| 11 | Медленные атаки: таймаут приёма, лимит соединений на клиента | slowloris умирает по таймауту |
| 12 | Запросы параметризованы, конкатенации параметров в текст нет | поиском по модулю; `' OR 1=1` — значение, не код |
| 13 | Ошибки не раскрывают внутренности (без стектрейса и структуры) | битый ввод — код RIH и incidentId, не текст исключения |
| 14 | Идемпотентность записи или ключ идемпотентности у партнёра | повтор запроса не плодит документы (повтор — 200 duplicate) |
| 15 | Таймауты каждой внешней операции явные, не «по умолчанию» | timeouts.md: операция → таймаут → что при превышении |
| 16 | Повторы только по классифицированным ошибкам, с джиттером | политика §17; 4xx не повторяются |
| 17 | Действия людей в аудите: показы ПДн, настройки, остановки обменов | отчёт «Действия пользователя» отвечает за 5 минут |
| 18 | Попытки атак логируются метаданными, без payload атакующего | журнал атак: тип и клиент, текста payload нет |
| 19 | Метрики и служебные маршруты не анонимны (кроме health) | снимок метрик без ключа — 401 |
| 20 | Threat model интеграции обновлена, остаточный риск подписан | страница в security/threat_models с подписью принявшего |

## Как применять

Ревьюер отмечает пункты по PR; «нет» по пунктам 1–13 — блокирующее
замечание до релиза, по остальным — задача с владельцем и сроком
(классификация риском, не вкусом, task_220). «Неприменимо» пишется
с причиной одной строкой: неприменимость без причины — та же
забывчивость.
