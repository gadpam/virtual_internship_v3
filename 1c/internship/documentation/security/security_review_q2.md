# Ревью безопасности интеграций Q2 (task_138)

Проведено по чек-листу security/checklist.md для интеграций
квартала: HTTP API магазина, лояльность, ТК, банк (SOAP), сервис
токенов, CDC и витрины, экспортёр метрик. Проверка исполняемая —
checks_security_review.py, а не чтение на глаз.

## Находки

| ID | Приоритет | Находка | Статус |
|---|---|---|---|
| SEC-1 | Высокий | Снимок метрик отдавался без аутентификации: объёмы, ошибки и состояния предохранителей — готовая разведка перед атакой | закрыто: маршрут за единой точкой проверки, checks_security_review |
| SEC-2 | Средний | Отказы выдачи токенов (неверный секрет, частота) превращались в 500: клиент не различает «неверный секрет» и «сервис сломан», мониторинг кричит об инциденте на каждый перебор | закрыто: 401/429 по префиксу кода в обработчике |
| SEC-3 | Средний | Проверка «дерево чисто» в checks_secrets считала несуществующий путь из-за относительного адреса и проходила вакуумно | закрыто: абсолютный корень от файла, полное дерево; попутно учебные пароли стенда оформлены allowlist-ом с причинами |
| SEC-4 | Низкий | Тестовое значение фикстуры сканера лежало в истории Git боевым форматом | принято как остаточный риск: значение выдумано, секретом не было; фикстура пересобрана по частям, исключение задокументировано в проверке истории |
| SEC-5 | Средний | Rate limit зеркала пентеста — в памяти процесса; боевой контур обязан считать по журналу или публикации | задача SEC-5 владельцу контура публикации, до вывода сервиса наружу; на стенде закрыто F-4 task_136 по журналу |

Пункты чек-листа 1–20 по остальным интеграциям: «да» с проверками
checks_tokens, checks_pdn, checks_pentest, checks_audit;
«неприменимо» — пункт 14 для чтения каталога (идемпотентность
не нужна читающему маршруту, причина: GET без побочных эффектов).

## Остаточные риски, принятые письменно

- Учебные ключи и пароли стенда (моки, bi_reader, rih) публичны
  внутри учебного контура. Принял: владелец стенда RIH;
  пересмотр — при любом выводе контура за пределы стенда.
- Пентест внешнего контура в этом квартале не проводится: сервисы
  внутри учебного стенда без внешнего адреса. Принял: владелец
  интеграций RIH; пересмотр — к выводу наружу (вместе с SEC-5).
- Платформенные настройки публикации (таймауты приёма, лимит
  соединений IIS/кластера) проверяются при развёртывании ИБ.
  Принял: владелец интеграций RIH; точка возврата — развёртывание.
