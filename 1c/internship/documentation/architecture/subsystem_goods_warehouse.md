# Подсистема «Товары и склад» (task_66)

## Назначение и пользователи

Учёт движения товаров между складами сети: поступление от поставщика,
перемещение между складами, остатки и цены, контроль минимальных
запасов. Пользователи: товаровед (поступления, перемещения, отчёты),
администратор (справочники, регламентные задания, журналы).

## Объекты

Справочники: Номенклатура (иерархия, свойства через ПВХ), Склады,
Контрагенты, ЕдиницыИзмерения, Упаковки. Документы: ПоступлениеТоваров,
ПеремещениеТоваров, УстановкаЦен. Регистры: накопления ТоварыНаСкладах;
сведений ЦеныНоменклатуры, МинимальныеОстатки, НаименованияНоменклатуры,
ЖурналОбменов, ЗамерыПроизводительности. Отчёты: ОстаткиТоваровПоСкладам,
ПланФактПоТоварам, ИсторияИзмененияЦен. Внешние контуры: загрузки CSV
(номенклатура, прайс), печатная форма поступления, мобильный снимок
инвентаризации.

## Процессы (схема словами)

Поставщик → ПоступлениеТоваров → (Транзакция + контроль пар) →
ТоварыНаСкладах приход на склад → ПеремещениеТоваров →
расход/приход между складами (подписка расширения: типы складов разные)
→ ОстаткиТоваровПоСкладам / ПланФактПоТоварам → решения товароведа.
Фон: ЗагрузкаПрайсаПоставщика (30 мин), ДвижениеГраницыУчётаТоваров
(час), журналирование всех событий (РИХ_Логирование).

## Ограничения

Контроль отрицательных остатков при расходе — backlog P1; остатки
читаются только срезом регистра, не перебором документов; цены —
периодический срез, не реквизит товара (ADR-1); платформа 1С в среде
разработки отсутствует — эксплуатация на стенде заказчика.
