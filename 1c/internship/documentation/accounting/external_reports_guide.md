# Внешний отчёт и обработка: инструкция бухгалтера (task_161)

## Подключить

Отчёт «Продажи по менеджерам с маржой», версия файла **1.2**;
обработка «Проверка полноты реквизитов», версия **1.0**.
Файлы выдаёт разработчик RIH, из других источников не подключать:
внешний файл выполняет код внутри базы.

1. Раздел администрирования → дополнительные отчёты и обработки.
2. Добавить из файла, выбрать выданный файл, указать раздел
   и пользователей.
3. Версия файла видна в заголовке открытого отчёта: при обращении
   в поддержку называйте её первой строкой.

## Пользоваться

- Отчёт: период и организация — как в ОСВ; менеджеры и маржа
  считаются по счетам 90.1/90.2 теми же цифрами, что оборотка.
- Обработка: период → «Проверить» → список документов с пустыми
  реквизитами и причинами. Пустой контрагент или организация —
  исправить до закрытия: такие документы ломают сверку месяца.

## При ошибке

Записать: версию файла из заголовка, текст сообщения (отчёт
говорит, какого счёта или субконто не хватает в этой версии
базы), период. Обращение — разработчику RIH; сообщение вида
«не работает» без версии не диагностируется.
