# documentation/accounting/

Учётная модель RIH: план счетов, проводки, методы расчёта.

| Файл | Что это | Задание |
|---|---|---|
| `model.md` | мини-план счетов (10–15 счетов), 8 операций холдинга с проводками, схема «документ → проводка → отчёт» | task_151 |
| `vat_and_cost.md` | методы: НДС, себестоимость (средняя/FIFO), расчёты с поставщиками, типовые расхождения | task_154 |

Инвариант модели: сумма оборотов по дебету всех счетов = сумме по кредиту.
Учебная честность: RIH строит свой регистр бухгалтерии как модель учёта,
а не копию БП; границы модели фиксируются здесь, а не обещаются «как в типовой».
