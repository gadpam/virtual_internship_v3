# Публикация HTTP-сервиса РИХ_Обмен (task_79)

## Адреса

- Внутри контура: публикация 1С на Apache/IIS, корень сервиса
  `http://<хост>/hs/rih/api/v1/...` (rootURL `rih` из метаданных).
- Снаружи стенда: nginx как обратный прокси перед публикацией 1С —
  сам nginx HTTP-сервисы 1С не отдаёт, только проксирует (и добавляет
  X-Forwarded-For, который читает защита от перебора task_81).

## Перепубликация после изменений

1. Выгрузить конфигурацию из EDT в ИБ (обновление конфигурации базы).
2. Переопубликовать веб-сервис штатной публикацией (файл default.vrd:
   сервис РИХ_Обмен включён, отладка выключена вне учебного стенда).
3. Проверить `GET /api/v1/health` без ключа: 200 и время сервера;
   затем `GET /api/v1/products` с ключом стенда.
4. Прогон коллекции Bruno (tools/api) против нового baseUrl.

## Честный статус в нашей среде

Веб-сервера с модулем 1С в среде нет (как и платформы): сервис написан
и зарегистрирован в метаданных, обработчики проверены зеркально и на
живом mock-контракте (checks_api_q2.py). Публикация — точка возврата
backlog P1-1; инструкция выше делает её рутиной на первом стенде.
