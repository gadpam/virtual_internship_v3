# documentation/compliance/

Регламентная и отраслевая отчётность: формы, проверки, квитанции, статусы.

Сюда складываются: описание выбранной отчётной формы и её контрольных
соотношений (task_119), регламент сроков и ответственных, протоколы
отклонений оператора и корректирующих отправок.

Отправленный отчёт неизменяем: корректировка — новая версия со ссылкой
на предыдущую и причиной, квитанция оператора хранится вместе с отчётом.
