# Тестовые стенды RIH (task_139)

«У меня зелёные, у тебя красные, код один» лечится не спорами,
а стендом: окружение собирается из репозитория одной командой,
данные — генератором с детерминизмом, а не копией продакшена
(копия тащит ПДн, объём и невоспроизводимые состояния).

## Три стенда

| Стенд | Назначение | Состав | Как поднимается |
|---|---|---|---|
| dev | разработка, данные любые | ИБ 1С разработчика, моки партнёров процессами (8010–8026), локальный PostgreSQL | вручную по README сервисов; секреты — учебные значения окружения |
| test | автоматические тесты, данные детерминированные | фикстуры `tests/fixtures/stand_data.json` + PostgreSQL (схема stand) + зеркала checks_* | одна команда: `src/scripts/stand_up.py` (0.4 с на профиле small) |
| integration | контрактные и сквозные сценарии против моков | mock_shop_api, лояльность, ТК, банк SOAP, трекер (docker-compose.test.yml в боевом контуре; на текущем стенде — теми же процессами, что dev) | compose одной командой там, где есть Docker; здесь — процессы стенда, состав и порты совпадают с compose |

Секреты стендов: значения не в этом файле — где брать, сказано
в описании каждого сервиса (окружение; учебные ключи allowlist-ом
task_134). Различия окружений, которые стенд обязан убрать:
версия данных (фикстуры с фиксированной датой 2026-01-15),
идентификаторы (SKU-0001, ORD-0001 — поименно), состав сервисов
(compose/процессы по одному списку портов).

## Детерминированные данные

Генератор `seed_fixtures.py` строит данные формулами от индекса:
500 товаров, 20 складов, 100 заказов, прайс и остатки (профиль
small; medium/large — тем же параметром для отладки и нагрузки
task_143). Случайности нет вообще, «сегодня» нет: два прогона
дают байт-в-байт один файл (проверено sha256), два подъёма
стенда — одну контрольную сумму заказов (297316.00 на small).

## Одна команда и время

```
src/scripts/.venv/bin/python src/scripts/stand_up.py small
```
Генерация → загрузка в PostgreSQL → дымовые запросы: 0.4 с.
Стенд, который поднимается час, не запускают; бюджет подъёма
test-стенда — секунды на small и минуты на large, замер — часть
прогона, а не отдельная доблесть. Платформенная ИБ и Docker
на текущем стенде отсутствуют: честная граница — test и dev
поднимаются автоматически, integration — процессами по составу
compose; точка возврата — машина с Docker.
