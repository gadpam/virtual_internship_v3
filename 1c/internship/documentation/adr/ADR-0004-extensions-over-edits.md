# ADR-0004: Доработки поведения — расширениями, а не правками основной конфигурации

- Статус: принято (task_48)
- Контекст: запрет перемещения между однотипными складами — локальное
  правило стенда; обновление основной конфигурации не должно его стирать.
- Решение: расширение РИХ_КонтрольПеремещений с подпиской ПередЗаписью;
  основная конфигурация не изменяется, правило отключается снятием
  расширения. Критерий: поведение, которое переживает обновление и не
  нужно всем установкам, — расширение; ядро учёта — конфигурация.
- Последствия: обновление типовой базы проще (task_65/287); правило
  тестируется отдельно (5/5 пар типов складов).
