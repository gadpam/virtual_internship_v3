# ADR-0009: Обмен RIH ↔ бухгалтерская база — КД 3 (EnterpriseData), не свой HTTP

Статус: принято (task_160). Обмен магистральный: документы уезжают
ежедневно десятками тысяч, сбой останавливает закрытие месяца.

## Контекст и критерии

| Критерий | КД 3 / EnterpriseData | Свой HTTP-обмен |
|---|---|---|
| Готовая схема для типовой бухгалтерии | есть у поставщика, обновляется с релизами | пишем и сопровождаем сами |
| Сопоставление НСИ | штатный механизм правил обмена | свой код сопоставления |
| Отладка расхождений | правила обмена версионируются (task_104), журнал типовой | наши логи, наш разбор |
| Обновление основы на релиз | правила проходят регресс task_287 | контракты перепроверяем вручную |
| Цена старта | ниже: схема готова | выше: протокол, ключи, повторы — всё своё |

## Решение

Обмен — Конвертацией данных 3 по EnterpriseData. Свой HTTP
остаётся транспортом интеграций с внешними партнёрами (Q2),
где готовой схемы поставщика нет по определению. Порядок
потоков жёсткий: НСИ с сопоставлением по бизнес-ключам →
документы → обратные статусы и проводки; документ раньше
своего контрагента — авария обмена, а не «доедет потом».

## Последствия

Ежедневная сверка количества и сумм по обе стороны (механика
task_156) обязательна: протокол обмена без контрольных цифр —
не доказательство (урок task_91). Правила обмена — версии
и регресс до продуктива (task_104, task_287).
