# ADR-0010: Граница между документооборотом и процессами RIH

Статус: принято (task_169). Вопрос через год «почему это не
в документообороте» отвечает ADR, а не «так исторически».

## Критерии выбора места процесса

1. **Юридическая значимость**: подписи, сроки хранения, аудит —
   сила документооборота; без неё его цена не окупается.
2. **Близость к данным**: процесс живёт там, где лежат его данные
   (ошибки обмена — рядом с журналом и очередью RIH).
3. **Частота и масса**: тысячи запусков в день против редких
   ручных — редкий ручной процесс дешевле автоматизированного.
4. **Состав участников**: корпоративные согласования с ролями
   и делегированием — документооборот; технологическая тройка
   шагов своих инженеров — RIH.
5. **Скорость изменений маршрута**: настройки владельца процесса
   против цикла разработки второй системы.
6. **Стоимость владения**: лицензии и сопровождение второй
   системы истины против доработки своей.

Главный запрет: процесс живёт ровно в одной системе. Вторая
получает состояния интеграцией (task_174); «для надёжности
в обеих» убивает надёжность первым расхождением статусов.

## Распределение процессов холдинга

| Процесс | Система | Критерии |
|---|---|---|
| Согласование договора | ДО | юр. значимость, аудит, роли |
| Согласование счёта на оплату | ДО | юр. значимость, сроки |
| Заявка на оплату | ДО | связь с договором, казначейство |
| Приказ по персоналу | ДО | хранение, ознакомление |
| Акт выполненных работ | ДО | основание закрытия договора |
| Разбор ошибок интеграций | RIH | данные и люди здесь (журнал, очередь) |
| Согласование корректировок данных учёта | RIH | рядом с проводками и сверкой |
| Внутренняя заявка на доступ/роль | RIH | технологический маршрут, аудит task_137 |
| Согласование изменения правила трансляции | RIH | владелец — учёт RIH (task_153) |
| Разработка и релизы | внешний трекер | своя модель задач и досок |
| Разовый запрос справки у бухгалтерии | без автоматизации | редкий ручной дешевле процесса |
| Расследование инцидента партнёра | внешний трекер + RIH-сверка | статусы задач трекера, данные RIH |

## Модель процессов RIH, которую строит спринт

Справочник видов процессов; карта маршрута данными (этапы, роли,
сроки, условия); экземпляры процессов; задачи с состояниями
и исполнителями-ролями. Сознательно меньше ДО: технологические
маршруты холдинга, а не второй корпоративный документооборот.
