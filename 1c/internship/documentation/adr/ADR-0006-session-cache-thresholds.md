# ADR-0006: Кэшируются только справочные пороги, на время сеанса

- Статус: принято (task_60)
- Контекст: минимальные остатки читаются каждым отчётом, меняются редко;
  остатки и цены нужны транзакционно свежими.
- Решение: РИХ_Кэш (ForSession) держит таблицу порогов; писатель порогов
  обязан вызвать СброситьКэш. Остатки, цены и движения не кэшируются
  никогда. Замер: 30 чтений из базы ~130 мс против ~0 из кэша; сценарий
  устаревания (500 вместо 900 без сброса) зафиксирован проверкой.
- Последствия: скорость повторных чтений растёт на два порядка; цена —
  дисциплина инвалидации у писателя, проверяется ревью пары
  «запись + сброс» как одного изменения.
