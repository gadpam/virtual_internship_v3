# Размышление по заданию task_004

**Задание:** Docker и docker compose: окружение RIH одной командой
**Дата:** 2026-11-17
**Время:** план 2 ч / факт 1.5 ч

## Что получилось

- Назначение всех 11 сервисов compose записано; понял, что внутри сети
  сервисы ходят по именам (postgres:5432), а наружу публикуются только
  порты из .env — поэтому смена POSTGRES_PORT не ломает межсервисные связи.
- Параметр NGINX_HTTP_PORT поменял через .env: compose-файл в git status
  чист — конфигурация окружения отделена от его описания.

## Учебная поломка: диагностика

Симптом (подключение 1С/psql): «connection to server ... failed: Is the
server running». Диагноз за минуту: сервер СУБД остановлен, сокета нет —
это не пароль, не сеть и не «Docker сломался»: сервис просто не поднялся.
Лечение: старт сервера; проверка `SELECT` под пользователем rih.
Порядок на будущее: сначала «жив ли сервис и слушает ли порт», потом
учётные данные и логику.

## Что не получилось
