# Размышление по заданию task_071

**Задание:** Портфолио: статья и публичный артефакт по итогам Q1
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 1 ч

## Что понял

Статья пишется легко, когда цифры уже лежат в заданиях: 52.2 → 0.13 мс
и цена вставки ×3.9 — это готовый сюжет «индекс как обмен», который
невозможно написать по памяти через месяц. Портфолио — не отдельный
жанр, а побочный продукт дисциплины «каждое решение с замером».

## Ошибка, которую я больше не повторю

Откладывать «привести репозиторий в порядок» на конец квартала:
история коммитов читалась как работа только потому, что коммит на
задание был правилом с task_0, а не уборкой перед демо.
