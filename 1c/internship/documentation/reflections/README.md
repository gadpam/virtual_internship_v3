# Размышления (рефлексия)

После каждого задания — один файл:

```
task_091_reflection.md
task_092_reflection.md
```

Шаблон — `../templates/ReflectionTemplate.md`.

Рефлексия — не формальность. За год накапливается 300+ заданий, и единственный
способ превратить их в навык — зафиксировать, что именно вы поняли и что
сделаете иначе. На собеседовании (task_298) спрашивают не «что вы делали»,
а «что вы поняли и как это изменило ваш подход». Ответ берётся отсюда.
