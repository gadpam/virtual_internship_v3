# Размышление по заданию task_121

**Задание:** OLTP vs OLAP: почему отчёт по оперативной базе — зло
**Дата:** 2026-11-17
**Время:** план 1 ч / факт 0.5 ч

## Что понял

«Отчёт тормозит» становится архитектурным аргументом только с цифрами
на непустой базе: проведение подорожало в 4.5 раза от одного фона
агрегации, и цена растёт с историей, а не с числом пользователей.
Второе: свежесть витрины — не техническая случайность, а договор
с бизнесом, записанный до постройки. «Продажи на сейчас» при этом
не возвращают аналитику в оперативную базу: интрадей-витрина
микропакетами — то же разделение ролей, только с меньшим лагом.

стабильные ×4.3–4.5, которым можно верить.
