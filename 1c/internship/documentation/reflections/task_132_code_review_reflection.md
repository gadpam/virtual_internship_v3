# Размышление по заданию task_132_code_review

**Задание:** Код-ревью спринта 22
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 1 ч

## Что понял

В спринте про надёжность дефекты нашлись не внутри механизмов,
а на их стыках: сага не смотрела на результат компенсации, деградация
не различала виды ошибок, загрузка молчала о падении. Каждый механизм
по отдельности был зелёным в своих тестах. Ревью, читающее границы
между слоями, оказалось продуктивнее ревью, перечитывающего слои.

## Ошибка, которую я больше не повторю

Игнорировать возвращаемое значение функции, чей неуспех — главный
риск сценария: «вызвали компенсацию» и «компенсация удалась» —
разные итоги саги.
