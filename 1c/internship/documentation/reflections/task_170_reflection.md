# Размышление по заданию task_170

**Задание:** Бизнес-процессы и задачи: карта маршрута и экземпляры
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 1 ч

## Что понял

Карта маршрута — граф состояний и данных, а экземпляр — конкретный
путь по нему с историей; аналитика потом строится именно по этим
данным, а не по воспоминаниям участников. Задача без ссылки
на объект в основании заставляет исполнителя начинать работу
с розыска контекста: процесс, стартующий из журнала одной
кнопкой, платит за запуск один раз, а не каждый раз человеком.

## Ошибка, которую я больше не повторю

Делать завершение задачи формальным «выполнена» без результата.
Этап, закрытый пустой задачей, не даёт аудиту ответа «что
именно сделали», а следующему этапу — основания продолжать.
