# Размышление по заданию task_062

**Задание:** АПК: анализ программы и консоли запросов как рабочий инструмент
**Дата:** 2026-11-17
**Время:** план 2 ч / факт 1 ч

## Что понял

Статический анализатор в 1С врёт предсказуемо: платформа вызывает код
строками (methodName регламентных заданий, подписки, внешние обработки,
наборы СКД), поэтому «метод нигде не вызывается» означает лишь «вызов
не виден поиску по .bsl». Из 28 кандидатов в мёртвый код настоящим
долгом оказался один — СброситьКэш без вызывающего писателя. Ценность
анализа не в списке, а в классификации: 27 отклонений с обоснованием
и 1 принятый долг — честный итог прогона.

## Ошибка, которую я больше не повторю

Удалять «неиспользуемый» экспортный метод по результатам поиска:
в 1С сначала проверяются строковые точки входа, потом — удаление.
