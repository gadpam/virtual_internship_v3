# Размышление по заданию task_014

**Задание:** Коллекции: массивы, структуры, соответствия, списки значений
**Дата:** 2026-11-17
**Время:** план 2 ч / факт 1.5 ч

## Замер: наивный vs эффективный поиск дублей

| Вариант | Сложность | 100 000 элементов |
|---|---|---|
| двойной цикл (каждый с каждым) | O(n²) | ~33 с (оценка по замеру среза 5 000: 0.083 с × 400) |
| один проход через Соответствие | O(n) | 0.022 с |

Разница — не «проценты оптимизации», а смена алгоритма: железо такой
разрыв не покупается. Та же идея в группировке прайса: Соответствие
«поставщик → его строки» одним проходом вместо повторных поисков
по исходной таблице.

## Что запомнил про выбор коллекции

Коллекция выбирается под частую операцию: частый поиск по ключу —
Соответствие; порядок и доступ по номеру — Массив; набор параметров
именами — Структура; передача набора в запрос — ТаблицаЗначений;
интерфейс с пометками — СписокЗначений. Ключом соответствия берут
ссылку, а не наименование строкой: переименовали товар — словарь
из наименований рассыпался на две группы.
