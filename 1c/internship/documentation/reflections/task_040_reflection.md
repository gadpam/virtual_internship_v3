# Размышление по заданию task_040

**Задание:** Локализация: RU/EN и многоязычные данные
**Дата:** 2026-11-17
**Время:** план 2 ч / факт 1.5 ч

## Что понял

Локализация делится на две разные задачи: интерфейс (синонимы метаданных —
платформа переключает сама) и данные (наименования товаров — наша модель).
Для данных регистр по языкам выигрывает у колонок тем, что третий язык —
это строки, а не релиз. Главное правило — fallback: отсутствие перевода
показывает базовое наименование, а не пустоту; пустой товар в отчёте
выглядит как потерянные данные, хотя потерян только перевод.

создания объекта, не заполняется никогда — поэтому он в чек-листе §13
первым пунктом.
