# Размышление по заданию task_169

**Задание:** Зачем свои процессы, если есть ДО: границы и ADR
**Дата:** 2026-11-17
**Время:** план 1 ч / факт 0.5 ч

## Что понял

Граница систем проводится критериями до первого процесса,
а не после десятого: цена ошибки — две системы истины для
одного согласования. ADR фиксирует не только решение, но
и проигравший вариант без высмеивания: через два года критерии
могут перевернуться, и ADR покажет, что именно изменилось.

## Ошибка, которую я больше не повторю

Выбирать место процесса по удобству разработчика. Юридическая
значимость и владелец данных отвечают на вопрос «где жить
процессу»; удобство отвечает только на вопрос «где нам
привычнее ошибиться».
