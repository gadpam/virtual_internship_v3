# Размышление по заданию task_024

**Задание:** Характеристики, единицы измерения и справочник «Склады»
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 2 ч

## Что понял

Характеристика — данные, а не метаданные: «Размер» заводится элементом
плана видов характеристик, и конфигурацию никто не перекомпилирует.
Подбор по свойствам — запрос с группировкой и условием ИМЕЮЩИЕ:
товар подходит, когда совпали все заданные свойства; перебирать товары
на клиенте — значит не понимать, зачем регистр соответствия существует.
Движения остатков — всегда в базовых единицах: упаковка живёт только
в документе, регистр про «коробки» не знает, иначе остатки несравнимы.
