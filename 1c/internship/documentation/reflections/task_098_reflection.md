# Размышление по заданию task_098

**Задание:** Конвертация данных 2.0: правила обмена справочников
**Дата:** 2026-11-17
**Время:** план 4 ч / факт 1.5 ч

## Что понял

Ядро обмена справочниками — не сериализация, а цепочка поиска
приёмника: идентификатор источника, затем смысловой ключ (артикул),
и только потом создание. Порядок этих трёх шагов определяет, будет
ли повторная загрузка скучной или породит дубли. Ручной код вместо
КД сделал эту цепочку видимой в ревью — у правил конфигурации она
спрятана в XML, который в git почти не читается.

## Ошибка, которую я больше не повторю

Считать «не найден в приёмнике» синонимом «создать»: сначала все
способы найти, создание — признание, что искали честно.
