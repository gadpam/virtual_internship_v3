# Размышление по заданию task_167

**Задание:** Доработка документооборота: реквизиты, печатные формы, процессы
**Дата:** 2026-11-17
**Время:** план 4 ч / факт 1 ч

## Что понял

Иерархия «штатно → внешне → расширением → правка» экономит
обновления годами: три из четырёх доработок этого задания не
потребовали ни строки в конфигурации. Печатная форма обязана
печатать версию документа своего согласования — «текущий
текст» под прошлую резолюцию превращает удобство в подлог.

## Ошибка, которую я больше не повторю

Зашивать лимит ветвления процесса в код. Лимит — данные
владельца процесса: его изменение с 500 тыс. до миллиона это
настройка на пять минут, а не задача разработчику с релизом
и согласованием окна.
