# Размышление по заданию task_031

**Задание:** Первый отчёт СКД: «Остатки товаров по складам»
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 2 ч

## Из каких частей состоит отчёт СКД

1. **Схема компоновки** — наборы данных и их поля, связи, группировки,
   ресурсы: «что вообще можно показать». Живёт с отчётом.
2. **Настройки** — выбранные поля, отборы, сортировки, итоги: «что показать
   в этом запуске». Вариант отчёта — сохранённые настройки.
3. **Компоновщик и процессор вывода** — платформа: строит запрос по
   настройкам, выполняет, раскладывает результат в макет.
4. **Табличный документ** — результат, который видит пользователь;
   сам по себе данных не хранит и при переформировании строится заново.

Поэтому «отчёт врёт» разбирают по частям: сначала набор (запрос),
потом настройки (отборы), потом макет (итоги) — в этом порядке.

Тянуть в набор данных «все поля справочника на всякий случай»:
каждое лишнее поле — чтение и память на каждую строку (приём task_36).
