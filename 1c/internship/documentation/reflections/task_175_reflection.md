# Размышление по заданию task_175

**Задание:** Кросс-системный отчёт: данные из RIH, бухгалтерской базы и ДО
**Дата:** 2026-11-17
**Время:** план 4 ч / факт 1.5 ч

## Что понял

Связь наборов — место тихих катастроф отчётности: декартово
произведение даёт правдоподобный отчёт с удвоенными суммами,
и находит его только контроль строк и сумм после каждой связи
по источникам по отдельности. Итог, сошедшийся «в общем», может
прятать два компенсирующих расхождения — сверка по контрагентам,
а не одной цифрой отчёта.

## Ошибка, которую я больше не повторю

Связывать наборы по наименованию контрагента. Наименования
пишут люди в трёх системах по-разному; ключ соответствия
по ИНН стоит дешевле одного отчёта, который вдвое врёт
на планёрке у руководства.
