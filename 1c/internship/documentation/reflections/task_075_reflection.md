# Размышление по заданию task_075

**Задание:** JSON и XML в 1С: штатные средства чтения и записи
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 1.5 ч

## Что понял

Формат выбирается по критериям, а не по привычке: у поступления JSON
занял 361 байт против 590 у XML, читается партнёром без схемы, но не
даёт жёсткой валидации, которую даёт XML с XDTO. Спецсимволы
(«Молоко „Домик" & Co») ломают именно ручную склейку строк — штатные
писатели экранируют сами, поэтому стандарт запретил склейку, а не
«рекомендовал осторожность».

## Ошибка, которую я больше не повторю

Угадывать типы при чтении JSON: дата, принятая за дату «потому что
похоже», ломается на первом партнёре с другим форматом; контракт
приводит типы явно.
