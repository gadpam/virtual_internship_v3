# Размышление по заданию task_179

**Задание:** Универсальные механизмы: допреквизиты, динамические списки, настройки
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 1 ч

## Что понял

Универсальные механизмы закрывают три четверти заявок без
релиза, но их цена — дисциплина видимости: допреквизит
проверяется цепочкой форма → отчёт → обмен при подключении,
а не жалобой через месяц. Настройки пользователя — тоже
продукт: без административной формы сброса поддержка лечит
«у меня всё пропало» расследованием по базе.

## Ошибка, которую я больше не повторю

Хранить значения допреквизитов без владельца-объекта.
Строка, не привязанная к объекту, не читается ни формой,
ни отчётом и превращается в мусор, который нельзя даже
корректно удалить.
