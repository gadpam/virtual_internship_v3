# Размышление по заданию task_173

**Задание:** Аналитика процессов: сроки, узкие места, загрузка
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 1 ч

## Что понял

Узкое место процесса почти всегда ожидание, а не работа:
67 часов в очереди против 0,3 часа руками. Оптимизация по
впечатлениям («у юристов всё лежит») лечит не тот этап и
портит отношения с людьми, которые работали быстро. Медиана
и p95 — честность против среднего, за которым прячется
один зависший процесс из ста.

## Ошибка, которую я больше не повторю

Мерить загрузку числом задач без типа и веса. Сравнивать
согласование договоров с визированием приказов одной цифрой —
получить рейтинг людей вместо аналитики процесса, после
которого отчёту перестают верить все.
