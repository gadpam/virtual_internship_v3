# Размышление по заданию task_064

**Задание:** CI/CD: GitHub Actions, сборка конфигурации, автопубликация
**Дата:** 2026-11-17
**Время:** план 4 ч / факт 1 ч

## Что понял

Ценность CI — не в количестве шагов, а в том, что красный шаг нельзя
обойти молча. Наш конвейер честно умеет три вещи (валидатор программы,
линтер конфигурации, тесты сервиса) и честно не умеет собирать .cf без
лицензий; попытка «опубликовать что-то похожее на .cf» разрушила бы
доверие к артефактам сильнее, чем отсутствие публикации. CI, который
врёт зелёным, хуже отсутствующего: отсутствующий хотя бы заставляет
проверять руками.

## Ошибка, которую я больше не повторю

Ставить в CI шаг, который не может выполниться в этой среде, «чтобы
была галочка»: сначала среда и лицензии, потом шаг.
