# Размышление по заданию task_048

**Задание:** Подписки на события, расширения и снимаемая доработка
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 2 ч

## Что понял

Расширение — это способ заплатить за локальность: доработка одной
площадки не должна ехать релизом всем. Цена — ограниченность (события,
заимствования) и риск, что поведение системы зависит от включённого
файла, которого нет в основной ветке. Поэтому учётная истина (движения,
остатки, права) расширением быть не может: отключили файл — потеряли
учёт. А вот «на этой площадке РЦ→РЦ запрещены» — как раз политика,
которой место в расширении с понятным сообщением пользователю.

## Ошибка, которую я больше не повторю

Ставить в расширение контроль, без которого данные становятся неверными:
снимаемая доработка по определению может отсутствовать.
