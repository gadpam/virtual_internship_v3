# Размышление по заданию task_081

**Задание:** Авторизация и безопасность HTTP-сервиса
**Дата:** 2026-11-17
**Время:** план 4 ч / факт 1.5 ч

## Что понял

Хранить хеш ключа вместо ключа — дешёвая страховка: база утекает
чаще, чем кажется, а SHA-256 обратно не разворачивается. Блокировка
перебора по журналу, а не по счётчику в памяти, переживает перезапуск
сервиса и видна поддержке: кто, откуда и когда долбил контур.

## Ошибка, которую я больше не повторю

Писать заголовки запроса в отладочный лог «временно»: временные логи
живут годами, а ключ из них не вычистить. Журнал пишет результат,
не заголовки — по построению, а не по дисциплине.
