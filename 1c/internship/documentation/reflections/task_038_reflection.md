# Размышление по заданию task_038

**Задание:** Валидация ввода и сообщения пользователю
**Дата:** 2026-11-17
**Время:** план 2 ч / факт 1.5 ч

## Что понял

Валидация показывает все ошибки сразу или заставляет пользователя играть
в «проведи—исправь—проведи» по кругу. Разница — в форме результата:
не первое исключение, а список (поле, текст). Поле в ошибке так же важно,
как текст: без него сообщение «количество должно быть больше нуля»
ищут глазами по всей табличной части. И валидация живёт на сервере
в общем модуле: проверка, существующая только в форме, — не проверка,
а подсказка, потому что обмены и API форму не открывают.

## Ошибка, которую я больше не повторю

Останавливать проверку на первой ошибке через Отказ внутри цикла:
пользователь чинит одну, проводит заново, находит вторую — и злится
уже не на данные, а на систему.
