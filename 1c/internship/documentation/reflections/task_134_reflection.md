# Размышление по заданию task_134

**Задание:** Управление секретами: где хранить пароли и ключи
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 1.5 ч

## Что понял

Секрет в истории Git не «удаляется» — он ротируется: репозиторий
помнит всё, и единственное лечение — сделать утёкшее значение
бесполезным. Стража в CI нужна не от злоумышленников, а от усталых
людей в пятницу: сканер ловит случайный коммит .env надёжнее, чем
глаза на ревью. А allowlist учебных ключей — часть дизайна: сканер,
который орёт на учебный контур, отключат целиком.

## Ошибка, которую я больше не повторю

Проверять «секретов нет» глазами по текущему дереву: история Git —
тоже репозиторий, и подтверждение даёт только сканер по ней.
