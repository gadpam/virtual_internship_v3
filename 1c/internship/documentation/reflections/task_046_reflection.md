# Размышление по заданию task_046

**Задание:** Регистры последовательности и оперативный учёт
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 2 ч

## Что понял

«Остаток» без уточнения — недоопределённый вопрос. Текущий остаток честен
сейчас и врёт про вчера; остаток по границе воспроизводим, но может
отставать от жизни. Последовательность с границей — механизм, который
делает вторую правду возможной: пока цепь документов непрерывна, цифры
закрытого периода не уплывут. Документ задним числом не «ломает» систему —
он показывает, зачем в отчёте подписывают, какой именно остаток на экране.

## Ошибка, которую я больше не повторю

Двигать границу «до последнего проведённого» без проверки непрерывности:
граница, перепрыгнувшая дырку непроведённых документов, обещает
неизменность, которой нет.
