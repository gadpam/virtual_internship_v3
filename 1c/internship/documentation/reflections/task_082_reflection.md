## Что понял

Ошибка API — часть контракта, а не сбой оформления: клиент магазина
по code решает «повторить», «чинить данные» или «звать человека»,
и это решение нельзя принимать по человеческому тексту. incidentId
замыкает контур: короткий ответ клиенту и полный текст в журнале —
та же пара, что в task_51 для пользователя, только для машины.
