# Размышление по заданию task_037

**Задание:** Управляемая форма документа: структура, команды, события
**Дата:** 2026-11-17
**Время:** план 2 ч / факт 1.5 ч

## Разница контекстов, как я её понял

`&НаКлиенте` — контекст формы на рабочем месте: есть элементы формы
и текущие данные, нет запросов и транзакций; код отсюда не может быть
истиной, потому что пользователь и сеть между ним и сервером.
`&НаСервере` — контекст формы на сервере: доступны данные формы одним
пакетом, можно запросы, нельзя «дотянуться» до открытого у пользователя
интерфейса. Общие модули — вообще без формы: правила, одинаковые для
формы, обменов и HTTP (туда уедет валидация task_38 и уехали даты/деньги).
Ошибка новичка — тащить серверные данные реквизитами на клиент «чтобы
были под рукой»: форма тяжелеет, данные устаревают, истина размывается.

## Ошибка, которую я больше не повторю

Делать серверный вызов на каждое изменение количества ради пересчёта
суммы: отзывчивость формы покупается клиентской арифметикой, а истину
всё равно пересчитает сервер при записи.
