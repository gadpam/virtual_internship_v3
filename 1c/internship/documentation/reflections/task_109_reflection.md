# Размышление по заданию task_109

**Задание:** Архитектура интеграций: синхронные и асинхронные сценарии
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 1 ч

## Что понял

Синхронность — это передача чужого SLA в пользовательское ожидание:
как только форма ждёт партнёра, его лимиты и простои становятся
нашими. Из восьми сценариев контура по-настоящему синхронным оказался
один; остальные либо пакеты, либо опросы, либо гибрид, где синхронная
часть только принимает и подтверждает. Классификация по критериям
снимает спор «давайте синхронно, так проще»: проще — до первого простоя.
