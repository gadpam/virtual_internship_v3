# Размышление по заданию task_182

**Задание:** T-SQL для анализа: соединения, окна, CTE, агрегаты
**Дата:** 2026-11-17
**Время:** план 3 ч / факт 1 ч

## Что понял

Оконные функции отвечают на вопросы расследования («доля,
первый, нарастающий») без самосоединений-монстров, а CTE
читается сверху вниз как конвейер из именованных шагов.
Главные запросы жанра — не отчётные, а диагностические:
дубли по бизнес-ключу и сироты находят грязь, которую
интерфейс не покажет никогда.

## Ошибка, которую я больше не повторю

Чистить «сирот» не глядя. Движение без регистратора может
быть легальным начальным остатком; диагноз ставится по типу
записи, а автоматический DELETE по результату запроса сирот —
способ удалить историю учёта одним скриптом.
