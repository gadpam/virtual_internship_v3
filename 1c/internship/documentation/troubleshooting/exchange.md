# Диагностика обменов: 5 типичных проблем (task_99)

| # | Проблема | Симптом | Диагностика | Лечение |
|---|---|---|---|---|
| 1 | Товар не найден в приёмнике | Документ обмена отклонён или создан пустой товар | Протокол загрузки: артикулы без пары; сверка справочников отчётом расхождений | Стратегия task_99: создать по пакету с пометкой обмена, довести человеком |
| 2 | Дубли после повторной загрузки | В приёмнике два товара с одним артикулом | Поиск по артикулу находит >1; протокол: «Создано» растёт при повторе | Цепочка поиска Ид → артикул → создать (task_98); слияние дублей отдельным регламентом |
| 3 | Непроведённые уехали | В приёмнике проведён документ, отменённый в источнике | Сверить проведённость по Ид документа в обоих узлах | Выгружать только проведённые (фильтр ПВД task_99) |
| 4 | Потеряно сообщение обмена | Номера принятых сообщений с дыркой; итоги узлов разошлись | Контроль номеров и счётчиков по узлам (task_101) | Переотправка диапазона номеров из источника, сверка итогов после |
| 5 | Частичная загрузка пакета | Половина документов есть, половины нет, ошибок «нет» | Протокол: число созданных ≠ числу в пакете; транзакция пакета? | Пакет — одна транзакция загрузки либо идемпотентные документы с повтором пакета целиком |

Общее правило диагностики: сначала протокол и счётчики, потом данные.
Обмен, который «просто не работает», без номеров сообщений и итогов
не диагностируется — поэтому контроль task_101 строится до жалоб.

## Восстановление после рассинхронизации (task_101)

1. Остановить отправку новых сообщений узлу (не приём: приём копит факты).
2. По контролю номеров определить диапазон потерь: последний принятый
   узлом и первый недостающий.
3. Переотправить диапазон из источника (сообщения хранятся до подтверждения).
4. Сверить остатки отчётом «Расхождения между узлами»: ноль строк —
   критерий завершения, а не «сообщения дошли».
5. Если расхождения остались после полной переотправки — это уже не
   потеря, а расхождение данных: разбирать по журналу изменений обоих
   узлов, master топологии (task_97) выигрывает спор.

Запрещено: «переслать всё с нуля» без шага 2 — полная перевыгрузка
маскирует причину и на больших объёмах стоит часы окна.
