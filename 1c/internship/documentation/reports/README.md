# Отчёты

Отчёты по заданиям, спринтам, кварталам и году. Именование:

```
task_091_description.txt      — описание выполненного задания
sprint_16_report.md           — отчёт о спринте
q2_report.md                  — отчёт о квартале
year_report.md                — годовой отчёт (task_306)
test_report_2026-03-14_load.md— отчёт о тестировании
```

Шаблоны — в `../templates/`. Отчёт без цифр и без честного списка «что не
сделано» не принимается: он не даёт наставнику понять, где вам помочь.
