# Регламент рассылки отчётов RIH (task_176)

В бухгалтерской базе рассылка — штатная подсистема БСП; в RIH
БСП нет, поэтому реализован аналог той же структуры: справочник
`РассылкиОтчётов` (…193), журнал `ЖурналРассылок` (…194),
регламентное задание (…195), модуль `РИХ_РассылкаОтчётов` (…196).

## Настройка рассылки

| Поле | Значение |
|---|---|
| Отчёт и вариант | имя отчёта конфигурации и вариант настроек |
| Расписание | «понедельник 08:00»; стендовый прогон — каждые 10 минут |
| Получатели | роль (руководитель подразделения), не список адресов |
| Формат | XLSX или PDF; большой отчёт — ссылкой на файл |
| Персонализация | параметр подразделения из пользователя-получателя |

Получатель с чужими подразделениями в отчёте — инцидент прав,
замаскированный под удобство: персонализация параметрами
варианта, а не ручным набором рассылок по филиалам.

## Цикл и журнал

1. Регламентное задание по расписанию формирует вариант отчёта
   каждому получателю с его подразделением.
2. Статус по каждому получателю пишется в журнал: сформирован →
   отправлен или ошибка с деталями.
3. Ошибка формирования в 7:55 уведомляет администратора сразу,
   а не звонком руководителя в 9:00.
4. Повтор после ошибки отправляет только тем, у кого в журнале
   нет «отправлен»: запись журнала — доказательство и защита
   от дубля одновременно.
5. Вложение сверх почтового лимита не отправляется: получатель
   получает ссылку на файл, путь фиксируется в журнале.

Опоздание рассылки находится мониторингом журнала (нет записей
к сроку — инцидент), а не вопросом получателей «а где отчёт».
Цифра в письме и цифра по ссылке из письма — один и тот же
файл формирования: два разных расчёта одного отчёта запрещены.
