## Регламент поставки

1. **Кто вправе добавить**: разработчик RIH после ревью кода —
   внешний файл исполняет произвольный код с правами пользователя,
   «прислали — подключил» запрещён. Безопасный режим и ревью обязательны.
2. **Как тестируется**: тестовый стенд, дымовой прогон формирования
   на эталонных данных (не открытие формы — половина поломок живёт
   в запросах), запись в реестр с версией конфигурации.
3. **Поставка одним комплектом**: файл, инструкция подключения,
   проверенные версии, порядок отката на предыдущий файл реестра.
4. **После обновления конфигурации**: дымовой прогон всех артефактов
   реестра в день обновления; скончавшийся от переименованного
   реквизита находится прогоном, а не пользователем через неделю.
   В CI без платформы — честный локальный прогон с фиксацией причины
   (контур task_64), не молчаливое «в CI нельзя».
5. **Отключение**: внешний артефакт отключается без последствий;
   который нельзя отключить — скрытое снятие с поддержки,
   к поставке запрещён.
