# Демо подсистемы «Товары и склад» (task_68)

Формат по DemoAndDefense.txt: 20 минут + 10 минут вопросы. Живой показ
в среде без платформы заменён исполнением сценария зеркальными
проверками на тех же числах; видеозапись — точка возврата (нет ИБ
для записи экрана), сценарий готов к показу на стенде с платформой.

## Сухие прогоны

Сценарий исполнен дважды целиком (поступление, контроль остатков,
валидация): оба прогона зелёны, числа совпали (остатки 11/6, отказ
на 11 при 10). На живом показе цифры те же — данные эталонные, ничего
не ищется на лету.

## Обратная связь (самопрогон, зафиксировано честно)

1. Раздел «что внутри» перегружен объектами — на показе оставить
   5 ключевых, остальное в ответах на вопросы.
2. Негативный сценарий показывать раньше позитивного отчёта: отказ
   системы понятнее, когда зритель уже видел остаток 10.

## Пять неудобных вопросов и ответы

1. «Что при миллионе движений?» — замерено: загрузка 1.69 с пакетами,
   отчёт по складам 119 мс (task_55/56).
2. «Два кладовщика одновременно перемещают один товар?» — управляемая
   блокировка пары склад+товар; второй ждёт, остаток не уходит в минус
   (гонка двух сеансов: ожидание 1.5 с, итог 4, не −2; task_45).
3. «Внешний прайс упал/битый?» — 3 попытки, битый файл пропускается
   с записью в ЖурналОбменов, прошлые цены не затираются (task_47).
4. «Почему не БСП?» — учебный контур без БСП (task_8); модули РИХ_
   спроектированы заменяемыми на БСП при переносе в боевую базу.
5. «Как обновлять прод?» — обработчик обновления идемпотентен,
   план и критерии отката — release_plan_q1.md (task_65).
