# Инструкция товароведа: поступление и перемещение (task_66)

## Оформить поступление товаров

1. Откройте «Поступление товаров» → «Создать».
2. Склад подставится сам, если за вами закреплён один склад; если
   складов несколько — выберите свой вручную (программа не угадывает).
3. Добавьте строки: товар, количество, цена. Количество больше нуля,
   дата — не в будущем: программа подсветит поле и объяснит ошибку
   списком над формой, исправьте все пункты сразу.
4. «Провести». Если товара не хватает для связанного перемещения позже —
   это нормально: контроль сработает на перемещении.
5. Печать: кнопка печатной формы (внешняя форма поступления, task_42).

## Переместить товар между складами

1. «Перемещение товаров» → «Создать»: склад-отправитель и получатель
   должны быть разных типов (например, РЦ → магазин) — однотипные
   перемещения запрещены правилом стенда, программа откажет при записи.
2. Строки: товар и количество не больше остатка отправителя; иначе
   проведение отклонится с текстом «Недостаточно товара» — проверьте
   остаток отчётом «Остатки товаров по складам».
3. Проведите и сверьте остатки получателя тем же отчётом.

## Если что-то пошло не так

Сообщение вида «Операция не выполнена… инцидент <ID>» — передайте ID
в поддержку: по нему найдут полный текст ошибки в журнале. Свои
действия перед ошибкой (какой документ, какой склад) приложите текстом.
