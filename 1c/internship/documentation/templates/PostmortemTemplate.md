## Действия

| № | Действие | Категория | Ответственный | Срок | Как проверим |
|---|---|---|---|---|---|
| 1 | | предотвращение / обнаружение / восстановление | | | |

Категории:
* **предотвращение** — дефект больше не может возникнуть;
* **обнаружение** — узнаём быстрее;
* **восстановление** — чиним быстрее.

Правило: минимум одно действие в каждой категории. Только «предотвращение»
означает, что следующий инцидент вы снова будете искать час.
