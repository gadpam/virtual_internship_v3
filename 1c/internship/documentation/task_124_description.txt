1. ЧТО ТРЕБОВАЛОСЬ
   Три способа отдать витрину наружу — файл, таблица СУБД, HTTP-поток —
   с честными замерами на миллионе строк и правилом выбора.

2. ЧТО СДЕЛАНО
   - Файл: CSV + gzip + манифест (версия формата sales-export/1, строк,
     сумма, SHA-256); получатель сверяет манифест до чтения данных.
     Обрезанный файл отклонён по сумме, неизвестная версия — тоже.
     В 1С: РИХ_Витрины.ВыгрузитьВитринуCSV с тем же манифестом.
   - Таблица СУБД: INSERT одной транзакцией; обрыв посередине показан
     откатом на 100 000 строк — частично записанных нет.
   - HTTP-поток: курсорные страницы по 5 000 (РИХ_Витрины.СтраницаВитрины);
     обрыв после первой страницы и дозабор с курсора довели выгрузку
     до 1 000 000 без повторов и без «сначала»; миллион одним ответом
     запрещён правилом в документации.
   - Замеры на 1 млн строк (documentation/analytics/export_methods.md):
     файл 1.53 с (35.5 МБ → 5.0 МБ gzip), таблица 2.10 с, HTTP 30.33 с
     при пике памяти клиента 6.6 МБ; оговорка стенда про psql на страницу
     записана рядом с цифрой, а не сноской.
   - Правило выбора по получателю таблицей: СУБД внутри контура, файл
     для редких срезов и недоступного получателя, поток — когда тянет
     сам потребитель; мобильному партнёру с плохой сетью — курсорные
     страницы, оба остальных способа вредны по именованным причинам.
