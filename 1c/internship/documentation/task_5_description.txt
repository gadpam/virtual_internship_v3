   Создать venv, написать скрипт: CSV (разделитель ';') → JSON-сводка,

   воспроизводимость двойного запуска.

2. ЧТО СДЕЛАНО
   - venv создан: internship/src/scripts/.venv (Python 3.11.2; pip 23.0.1,
     setuptools 66.1.1; внешних пакетов скрипту не нужно — только
     стандартная библиотека, поэтому окружение пересоздаётся одной
     командой и без сети). В Git venv не попадает (правило .venv/ есть).
   - Скрипт src/scripts/first_python_check.py:
     * csv.DictReader с разделителем ';', колонки берутся по имени
       (planned_quantity/planned_amount) — перестановка колонок не страшна;
     * сводка пишется json.dump(..., ensure_ascii=False, indent=2);
     * HTTP — urllib.request; зафиксированы статус, Content-Type и тело;
     * ошибки (отсутствует файл, битый JSON настроек, HTTP >= 400, сеть)
       превращаются в CheckError → сообщение в stderr и sys.exit(1).
   - Запуски: основной + --check-errors (демонстрация трёх ошибок) +
     два повтора; сводки двух запусков совпали байт в байт (cmp).
