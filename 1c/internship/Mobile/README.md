# Mobile/ — мобильная конфигурация RIH

Заготовка под четвертый квартал (sprint_43, task_253…task_258).
Мобильная платформа 1С — это отдельный проект со своей конфигурацией и ограничениями.

## Что появится здесь по заданиям

| Задание | Артефакт |
|---|---|
| task_253 | Мобильный проект, схема экранов, оценка объёма данных на устройстве |
| task_254 | Выгрузка данных на устройство, локальное хранение, офлайн-операции |
| task_255 | Протокол синхронизации, правила разрешения конфликтов, очередь разбора |
| task_256 | Сценарий сканирования, UX «в перчатках», обратная связь, обработка ошибок |
| task_257 | Публикация приложения, аутентификация, контроль версий, процесс обновления |
| task_258 | Телеметрия, отчёт «Мобильные операции», отзыв доступа, риски |
