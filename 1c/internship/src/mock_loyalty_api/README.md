# Mock-сервис «Программа лояльности»

Имитирует внешний сервис бонусной программы: баланс карты, начисление, списание,
сторно. Главное свойство — поддержка идемпотентности по `operationId`: повторный
запрос возвращает тот же результат и НЕ начисляет баллы дважды (задание task_92).

Запуск: `uvicorn app.main:app --host 0.0.0.0 --port 8021` (или docker compose).

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | статус |
| GET | `/api/v1/cards/{card}/balance` | баланс и история операций |
| POST | `/api/v1/accrue` | начисление (обязателен `operationId`) |
| POST | `/api/v1/redeem` | списание (обязателен `operationId`) |
| POST | `/api/v1/reverse` | сторно операции (возврат чека) |

## Поведение, которое надо проверить в task_92

1. Повторный POST с тем же `operationId` → тот же ответ, `duplicate: true`, баланс не изменился.
2. `reverse` для несуществующей операции → 404.
3. Двойное `reverse` одной операции → 409 (сторно не выполняется дважды).
4. Сервис недоступен → клиент 1С должен перевести операцию в очередь (task_95, task_131).
