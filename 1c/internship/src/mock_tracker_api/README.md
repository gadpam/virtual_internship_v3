# Mock-сервис «Трекер задач»

Имитирует внешнюю систему управления задачами (аналог Jira/Redmine), в которую RIH
отправляет инциденты и наряды на разбор ошибок интеграции. Используется в
заданиях task_171 (сроки, эскалация, делегирование), task_172 (рабочее место исполнителя),
task_173 (аналитика процессов) и task_174 (интеграция процессов RIH с внешними трекерами).

Запуск: `uvicorn app.main:app --host 0.0.0.0 --port 8024`

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | статус |
| POST | `/api/v1/issues` | создать задачу (idempotency по `externalRef`) |
| GET | `/api/v1/issues` | список задач (`status`, `assignee`, `due_before`) |
| GET | `/api/v1/issues/{id}` | карточка задачи |
| PATCH | `/api/v1/issues/{id}` | смена статуса/исполнителя/срока |
| POST | `/api/v1/issues/{id}/comments` | комментарий (журнал разбора) |
| GET | `/api/v1/sla` | задачи с нарушенным SLA (для аналитики сроков task_173) |

## Модель статусов

`new → in_progress → resolved → closed`, ветка `blocked` (ждём данные от партнёра).
Переходы проверяются сервером: недопустимый переход → 422 с текстом причины.
