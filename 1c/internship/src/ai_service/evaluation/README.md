# Оценка качества поиска и ответов (task_238, task_244)

Здесь живут эталоны и метрики. Без них любое изменение промпта или поиска — лотерея.

## Состав

| Файл | Назначение | Задание |
|---|---|---|
| `golden_questions.json` | 30 эталонных вопросов + ожидаемые источники | task_238 |
| `provocative_questions.json` | 15 вопросов «на галлюцинации» | task_243 |
| `answer_rubric.md` | Критерии ручной оценки ответа по шкале 1–5 | task_244 |
| `run_evaluation.py` | Прогон: метрики hit@1, hit@5, MRR, recall@10 | task_238 |
| `reports/` | Результаты прогонов по версиям конфигурации | task_240, task_250 |

## Метрики

- **hit@k** — доля вопросов, где правильный источник попал в первые k результатов;
- **MRR** — средняя величина, обратная рангу первого правильного источника;
- **recall@K** — доля найденных правильных источников из всех ожидаемых;
- **refusal rate** — доля честных отказов на вопросах вне корпуса (чем выше, тем лучше);
- **hallucination rate** — доля ответов с утверждениями без источника (цель — 0).

## Правила

1. Эталонный набор — актив проекта: пополняйте его реальными вопросами пользователей.
2. Любое изменение (чанкование, K, веса гибрида, промпт, модель) — только через прогон
   оценки и сравнение с предыдущим отчётом.
3. Результаты на 30 вопросах шумные: не делайте выводов по разнице 1–2 %.
4. Ночной прогон оценки подключается к CI (task_244, task_266).
