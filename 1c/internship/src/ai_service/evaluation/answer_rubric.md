# Критерии оценки ответа ассистента (task_244)

Оценка вручную по шкале 1–5 для каждого критерия. Два оценщика → при расхождении
более 1 балла обсуждаем и фиксируем причину (иначе сравнение конфигураций бессмысленно).

| Критерий | 1 | 3 | 5 |
|---|---|---|---|
| Корректность | утверждения противоречат корпусу | частично верно, есть неточности | полностью соответствует источникам |
| Полнота | ответ не покрывает вопрос | покрыта основная часть | покрыт вопрос и важные оговорки |
| Источники | источников нет | источники есть, но не ко всем утверждениям | каждое утверждение имеет ссылку |
| Честный отказ | выдумал ответ при отсутствии данных | ответил уклончиво | явно сообщил, что в документах не найдено |
| Полезность | ответ нельзя применить | требует доработки пользователем | готов к действию (шаги/ссылки) |
| Язык | путано, жаргон | понятно, но многословно | кратко, структурно, по делу |

## Сводные метрики прогона

- средний балл по критериям;
- доля ответов с галлюцинациями (цель — 0);
- доля корректных отказов на провокационных вопросах (цель — 100%);
- доля ответов с полным цитированием (цель — ≥ 90%).

## Правила прогона

1. Одна конфигурация = один отчёт в `reports/` с датой, версией корпуса, параметрами.
2. Сравнение конфигураций — только на одном и том же эталонном наборе.
3. Изменение системного промпта = изменение конфигурации: прогон обязателен.
