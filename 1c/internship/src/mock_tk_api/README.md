# Mock-сервис «Транспортная компания» (TK)

Имитирует API службы доставки с ограничением частоты запросов (rate limiting),
что отрабатывается в задании task_93: расчёт стоимости, создание заявки, статус,
этикетка, трекинг.

Запуск: `uvicorn app.main:app --host 0.0.0.0 --port 8022`

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | статус, текущие лимиты |
| POST | `/api/v1/calculate` | расчёт стоимости доставки (город, вес, объём) |
| POST | `/api/v1/shipments` | создание заявки (идемпотентность по `externalId`) |
| GET | `/api/v1/shipments/{id}` | статус заявки |
| GET | `/api/v1/shipments/{id}/label` | этикетка (PDF-заглушка) |

## Rate limiting (проверяется в task_93)

- Лимит: 10 запросов в минуту на ключ (настраивается `MOCK_TK_RATE_LIMIT`).
- При превышении: `429` + заголовок `Retry-After` в секундах.
- Клиент 1С обязан уважать `Retry-After` и применять экспоненциальную задержку с
  джиттером (практика из task_128).

## Режимы сбоев

Заголовок `X-Fault-Mode`: `error500`, `timeout`, `slow`, `garbage`, `label_failed`.
