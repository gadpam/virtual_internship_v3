# Состав консьюмера

- `config.py` — загрузка настроек из `.env`/окружения, значения по умолчанию.
- `main.py` — цикл чтения очереди: ack/nack, счётчик повторов, DLQ, корректная остановка.

Если aio-pika недоступен на вашем стенде, консьюмер не запустится — но логика
обработки переносится в 1С один в один: в заданиях task_110 и task_112 вы реализуете ту же
таблицу «код ответа → действие» средствами регламентного задания и регистра
`РИХ_ОчередьИнтеграции`.
