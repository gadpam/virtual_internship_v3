# Расширение «РИХ_КонтрольПеремещений» (task_48)

Назначение: дополнительный контроль перемещений без изменения основной
конфигурации. Основная конфигурация о расширении не знает: отключение
расширения возвращает систему к исходному поведению (проверяется
включением/отключением в ИБ при импорте).

## Что внутри

- Подписка на событие «Перед записью» документа ПеремещениеТоваров
  (EventSubscriptions/ЗапретПеремещенияМеждуОднотипными.xml в этом каталоге
  как описание; в EDT расширение собирается из этих исходников).
- Обработчик (Module.bsl рядом): запрещает перемещение между складами
  одного типа — РЦ→РЦ и Магазин→Магазин бессмысленны для нашей логистики,
  а Транзитный участвует свободно.

## Trade-off: расширение против правки конфигурации

| Критерий | Расширение | Правка конфигурации |
|---|---|---|
| Обновление основной конфигурации | не конфликтует | риск конфликтов слияния |
| Скорость доработки | быстро, отдельным файлом | релиз конфигурации |
| Производительность/контроль типов | события и заимствования ограничены | полный доступ |
| Риск «забыли отключить» | поведение меняется без релиза | поведение = код в репозитории |

Правило проекта — в CodingStandard.md §14: локальный контроль одного
заказчика/площадки — расширением; поведение, обязательное для всех
установок и завязанное на движения, — в основную конфигурацию.
